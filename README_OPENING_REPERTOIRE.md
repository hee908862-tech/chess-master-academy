## 설계와 완료 기준

기존 강의 수순을 재사용하며 계정 progress의 별도 `opening_repertoire_v1`에 선택·시도·도움/이탈을 저장한다. 오프닝 화면 안에서 선택→해설 학습→답 가린 재현→위치별 도움/이탈→약한 위치 또는 전체 재시도→새로고침 이어하기를 제공한다. 새 메뉴를 늘리지 않는다. 학습 완료에서 같은 레슨 복습으로 연결하고 기존 탐색/북마크로 복귀할 수 있다.

핵심은 London4/Jobava3개. 기존 나머지48강도 같은 저장·재현 모델로 선택할 수 있으나 새 심층 설명의 적용 범위는 핵심7개다. 핵심15개 위치에 배치/상대 목표/가능 계획/예외를 자체 작성하고 나머지 위치는 기존 착수 해설과 규칙 기반 사실을 재사용한다. 완전한 레퍼토리 이론이나 교육 효과 입증을 주장하지 않는다.

복습은 선택한 색의 수를 재현하며 상대는 등록된 예시로 응수한다. 백/흑 모두 지원한다. 서버가 기대 수·후보·다음 해설을 복습 응답에서 생략하고 UI에서 기존 탐색 보드/레슨 선택/제목/후보를 숨긴다. 도움말 열기는 도움 집계가 아니며 실제 수·설명 힌트와 복습 중 기존 탐색 복귀는 도움으로 기록한다. 공개 강의 자료이므로 외부 창에서 답을 찾아보는 행위까지 막는 시험 시스템은 아니다.

London 기본형의 ...Bd6 뒤 Bg3와 Bxd6 Qxd6 Bd3를 별도 등록 분기로 인정한다. 다른 합법 수는 이 레슨의 미등록 수이며 악수나 실력 감점이 아니다. 엔진을 새로 호출하지 않는다. 불법 수/승격 취소는 기록을 바꾸지 않는다.

시도 ID/root ID·콘텐츠 해시·강의/분기ID·수순/위치FEN·입력/도움·revision을 보존한다. 재시도는 새 ID로 보관하며 계열 도움/이탈과 레슨 누적, 첫 복습 결과를 지우지 않는다. 완주는 해당 예시 재현일 뿐 독립 숙련/진단 크레딧이 아니다. 개정 해시 불일치 시 이전 위치와 기록을 보존하고 진행을 막으며, 사용자가 이전 시도를 마친 뒤 새 콘텐츠를 시작한다.

기존 `ProgressState` 필드 CAS와 매 쓰기의 nonce를 사용한다. 동시 같은 revision은 한 요청만 저장된다. 선택16개, 보관시도64개, 시도당256행, 전체1MiB 상한. 상한에서는 쓰기를 거절하며 기존 기록을 자동 삭제하거나 초기화하지 않는다. 장기 다량 사용의 보관 확대/내보내기는 이번 범위가 아니다.
