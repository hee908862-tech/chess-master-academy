PC는 보드/설명/노트 2열, 1050px 이하는 보드 우선, 760px 이하는 설명 접기와 세로 배치. 일반 조작 버튼 최소 44px, 보드는 화면 폭에 맞추므로 작은 화면의 각 칸은 44px 미만일 수 있다. 모바일 훈련실에서는 고정 하단 내비게이션 대신 문서 흐름 안의 상단 이동 버튼을 사용해 보드를 가리지 않는다. 다른 화면의 기존 메뉴는 유지한다. 새 훈련에는 프리무브가 없으며 안내를 표시한다. 기존 대국·진단 AI·v9 퍼즐의 프리무브는 유지한다.

## 저장과 안전 경계

- 새 `learning_progress(code PRIMARY KEY, state TEXT)` 테이블을 startup의 `CREATE TABLE IF NOT EXISTS`로 추가한다. 기존 accounts/sessions/progress/문제은행을 변경하거나 초기화하지 않는다. Docker COPY에 새 모듈만 추가한다.
- 새 학습 기록의 읽기→변경→저장은 한 트랜잭션: SQLite `BEGIN IMMEDIATE`, PostgreSQL `INSERT ... ON CONFLICT DO NOTHING` 후 `SELECT ... FOR UPDATE`. session ID와 revision이 일치해야 동작한다. 실패는 rollback한다.
- 기존 progress JSON을 쓰는 화면이 새 테이블을 덮어쓸 수 없다. **기존 progress 자체의 전체 read-modify-write 경쟁은 해결 범위 밖**이다.
- PostgreSQL SQL 경로는 구현했지만 이 환경에 서버가 없어 실제 PostgreSQL 동시성/업그레이드 검증은 미실행이다. 운영 반영 전 백업 및 별도 스테이징 확인 필요. 이번 작업은 운영에 연결하지 않았다.
- 새 테이블을 기존 프로필의 기록 초기화 기능과 자동 연결하지 않는다. 기존 초기화 화면의 문구는 새 훈련 기록까지 지운다고 보장하지 않으며, 사용자 요청 없이 삭제 범위를 넓히지 않는다.
- 엔진은 기존 STOCKFISH_PATH만 사용한다. 유료 API/새 비밀키/외부 서비스가 없다. 엔진 탐색은 동기 실행이며 상황 학습 중 계정 row lock을 유지한다. 대규모 동시 사용 부하 검증은 미실행이다.

## 후속 보완: 공통 태그·저장 경로·기록 신뢰도

- 카드에 실제 Lichess 학습 태그와 출처를 저장한다. 내 대국 카드는 규칙으로 입증한 즉시 메이트/승격/언더프로모션/체크 대응만 태그로 사용하며, 알 수 없는 전술 이름을 추측하지 않는다. 이전 카드도 원본/규칙으로만 태그를 보충한다.
- `similar_to` 선택은 확인된 태그 교집합이 필수다. 미노출 ID뿐 아니라 동일한 보드 배치·차례·캐슬링·앙파상 권한의 다른 ID도 제외한다. 비교 원본·공통 태그·선택 방식을 결과와 함께 저장하며, 독립 랜덤 문제는 전이 성공에 포함하지 않는다. 적합한 문제가 없으면 409로 안내하고 무관한 문제로 대체하지 않는다.
- `/api/learning/path`는 원본 카드, 선택 이유, 4단계의 선택 카드/모드/상태/세션/결과, 현재 단계와 revision을 저장한다. 복습 완료로 due가 미래가 되어도 원본 카드가 유지되어 상황 대국으로 이어진다. 자유 훈련이 active를 바꿔도 저장된 경로 세션을 복원한다.
- 복습·새 문제·상황 대국은 **시도 결과 저장**으로 단계를 완료한다. 성공 여부는 별도 outcome에 보존한다. 개념은 명시적인 읽기 확인으로 완료한다. 복습 원본·공통 태그 후보·엔진이 없으면 단계별 이유와 함께 skipped로 기록하며 가짜 성공 기록을 생성하지 않는다. 전부 처리한 경로는 다음 날짜 또는 명시적 새 경로 선택으로 새로 만든다. 이전 경로 기록은 보존한다.
- 힌트/정답 공개/오답은 착수 완료 전에도 카드의 UTC 날짜별 exposure에 즉시 저장한다. 재시작으로 지울 수 없다. 같은 카드의 무도움 복습 승급은 하루 한 번만 가능하며 이후 반복은 due나 성공 횟수를 늘리지 않는다. 과거 날짜 시도/노출과 당일 재시도는 구분한다.
- 능력 표본은 새로운 위치의 첫 시도와 적격 지연 재검증만 사용한다. 반복·도움·오답 후 재시도·미검증 대안은 독립 표본이 아니다. 동일 위치 5회 반복으로 근거 부족을 해제할 수 없으며, 서로 다른 위치 5개가 필요하다. 이전 버전의 독립성 근거 없는 기록은 보존하되 소급하여 독립 표본으로 인정하지 않는다.
- 연습/검증 횟수를 별도로 표시한다. 최근 30개 시도의 카드별 최신 검증 결과가 미달성이면 다음 경로 선택 시 우선한다. 후속 검증 성공은 이전 실패 우선순위를 해제한다.

추가 재현 테스트: 공개/힌트/오답 → 미완료 재시작 → 정답, 과거 시도 후 당일 5회 반복, 동일 영역이지만 태그 불일치, 미노출 공통 태그 선택 근거, due가 미래가 된 뒤 원본 상황 시작, 자유 훈련/앱 재생성 후 경로 복원, 빈 경로/엔진 없음/후보 없음의 건너뛰기, PC·모바일 경로 reload.
