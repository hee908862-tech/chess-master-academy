# Chess Master Academy v8.1 — v8.0 기반 동작·통계 보완판

이 패키지는 **v8.0 전체 코드를 기반으로** 수정했습니다. v7을 별도 업로드할 필요는 없습니다. 기존 계정과 PostgreSQL 데이터 URL은 유지합니다.

## 이번에 수정한 부분
- 진단에서 21문항 연속 1수 메이트 출제: 메이트는 7문항으로 제한하고, 서로 다른 주제가 교차되도록 바꿨습니다. **주의: 남은 기물 획득/오프닝/엔드게임 문항은 아직 난이도가 검증된 문항은행이 아니므로 실력 평가 신뢰도가 제한됩니다.**
- 진단 점수: 정답 우선, 제한적인 풀이 시간 보정(최대 8% 손실), 오답 0점. 엔진 정확도 30%.
- 진단 마지막 AI 대국: 기존 백 12수 종료 규칙 삭제. **10분+착수당 5초**, 실제 체스 종료 또는 시간 종료까지 진행. 서버 쪽에서 시계 기록·복원. 모바일/PC 화면의 착수 즉시 반영.
- 일반 AI 대국: 무제한, 래피드(10+5), 블리츠(3+2), 불릿(1+0). 백·흑 각각 시간 계산.
- 앙파상: 사용자 이동 직후 상대 폰을 낙관적 화면에서도 즉시 제거. 승격 임시 표시 추가.
- 힌트 사용: 서버 기록에 `hint_used`, `hint_plies` 보존. 힌트를 사용한 대국은 새 규칙별 승률에서 제외. 과거에 힌트 여부가 저장되지 않은 대국은 **확인 불가능**하므로 승률 통계에서 제외.
- 복기: 힌트가 사용된 착수를 보라색 계열로 표시.
- 프로필: 시간제한 유형별 대국수 / 승무패 / 승률 표시.
- `/api/game`을 다시 열 때 서버 시계를 기준으로 시간 초과 판정.
- 정적 회귀 검사 `test_v81_regression.py` 추가.

## 미완료 / 검증 한계
- **난이도 1→7이 실제로 단계별로 어려워지는지 입증하지 못했습니다.** 기존 원천 문제은행 자체가 제한적입니다. 등급은 비공식 실험 지수입니다.
- **킹·폰 엔드게임의 기계적인 폰 밀기 문제를 제대로 된 킹 활동·오포지션·승격 계산 문제은행으로 교체하지 못했습니다.** 해당 영역 점수를 실력 진단에 그대로 반영하면 부정확할 수 있습니다.
- 체스닷컴/리체스의 공개 교육 카테고리를 검토했습니다. 원본 문제 데이터는 무단 복제하지 않았습니다. 검증된 독립적인 퍼즐 문제은행의 구축이 필요합니다.
- 실제 Stockfish 대국/시간 만료/DB 통합 테스트는 **이번 제작 환경에 python-chess가 없어 진행하지 못했습니다**. Python 구문·JavaScript 문법·정적 회귀 검사는 통과했습니다.
- 기존 데이터의 삭제/마이그레이션은 수행하지 않았으나 PostgreSQL을 사용하는 앱이므로 배포 전 백업 권장.

## 점수 산출식 — 이 v8.1 버전
정답 시 문항 점수: `P = 100 × [0.92 + 0.08 × min(1, (70 + 15d) / max(0.1,t))]`, 오답은 0. (`d`: 표기 난이도 1~7, `t`: 풀이 초)

분야 점수: `D = Σ(P_i × (0.75+0.07d_i)) / Σ(0.75+0.07d_i)`

문제 총점: `Q = 7개 분야 점수의 산술평균`

엔진 실전 정확도 근사치: `A = 평균[100 × exp(-max(0,센티폰 손실)/180)]`

최종 내부 지수: `I = round(10 × (0.7Q + 0.3A))`. Stockfish 평가가 없으면 `I=round(10Q)`이고 **문제만 평가한 예비 지수**로 표시됩니다.

칭호: 0~299 입문자 / 300~549 초급자 / 550~749 중급자 / 750~1000 숙련자.

이 지수는 FIDE/Chess.com/Lichess의 레이팅이 아닙니다. **문항 난이도 보정이 완료되지 않아 실력의 객관적 측정 도구로 사용할 수 없습니다.**

## 배포
1. Render에 연결된 데이터베이스를 백업합니다.
2. ZIP 내부 `chess_master_academy_v8_1/`의 **내용만** 기존 GitHub 저장소 루트에 덮어씁니다.
3. Render의 `DATABASE_URL`은 변경하거나 삭제하지 않습니다.
4. Docker 자동 배포가 끝나면 새로고침 후 일반 대국(한 수, 앙파상, 시간제한) → 프로필 통계 → 진단 이어하기를 순서대로 테스트합니다.
5. 새로 만든 진단은 실제 AI 종료까지 진행합니다. 이미 평가 중인 v8 세션은 서버가 새 형식으로 시간을 초기화하여 이어갈 수 있습니다.
