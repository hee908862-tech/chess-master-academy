# Chess Master Academy v5 — 종합 업데이트

기존 GitHub `hee908862-tech/chess-master-academy`와 Render Web Service에 대한 **업데이트 패키지**입니다. 기존 `DATABASE_URL`, Postgres, 계정 정보를 유지합니다. 데이터베이스는 업데이트 전에 백업하세요.

## v5 기능

- **아카데미:** 오프닝을 무작정 따라 두는 방식 대신 분야별 포지션 실습. 같은 개념을 다른 체스판에서 직접 적용합니다. 기존 커리큘럼의 설명은 유지합니다. 강의 완료는 실습 해결 후 서버에서 기록합니다. 현재 기초 시나리오 수는 제한적이며 미러링 변형을 포함해 총 2~4개/과정입니다. 대규모 콘텐츠 완성은 아닙니다.
- **퍼즐 재도전:** 화면뿐 아니라 서버의 채점 세션까지 재설정합니다. 재도전도 별도 풀이 이력으로 저장됩니다.
- **AI 난이도:** 1~10. Stockfish 지원 시 `UCI_LimitStrength`/`UCI_Elo` 설정을 사용하며, 무료 인스턴스 자원에 따라 반응속도가 달라질 수 있습니다. 난이도 숫자는 공인 Elo 값이 아닙니다.
- **오프닝:** 이탈리안, 퀸즈 갬빗, 시실리안, 런던, 카로칸, 프렌치, 스카치, 킹즈 인디언, 루이 로페즈, 잉글리시의 백/흑 총 20개 기초 코스. 체스판 위 화살표 힌트와 주요 아이디어 해설을 제공합니다. 수순은 해당 코스의 대표적인 하나의 변화일 뿐, 모든 응수 변화를 다루지는 않습니다.
- **기록 초기화:** 프로필에서 PIN과 '초기화'를 입력해야 삭제됩니다. 개인 코드/계정은 남고 `progress` 기록만 초기화됩니다. 복구 불가.
- **대국 기록/복기:** 완료한 대국의 백·흑 수순, SAN, 포지션, Stockfish 신속 분석(수별 centipawn loss, 최선/훌륭/좋음/부정확/실수/블런더) 및 간단한 코멘트. 평가 라벨은 탐색 시간이 짧은 근사값이며 Chess.com 등 타사 표준과 동일한 판정이 아닙니다. '탁월'은 엄밀한 희생·유일수 판정이 필요한 별도 개념이므로 현 버전에서 제공하지 않습니다. Stockfish 사용 불가 시 엔진 평가 라벨 대신 '미평가'로 표시합니다. 대국당 최대 200반수까지 분석합니다.

## 기존 GitHub에 업데이트

1. Render의 Postgres 데이터베이스를 가능한 방식으로 백업합니다.
2. 이 압축의 **chess_master_academy_v5 폴더 안 파일과 폴더**를 GitHub 저장소 최상위에 업로드합니다. 동일 경로의 기존 파일은 새 버전으로 교체합니다.
3. `public` 하위의 이미지·스크립트를 포함해 전체 업로드합니다.
4. `server.py`, `public/index.html`, `public/app.js`, `public/extended.js`, `public/v4.js`, **신규 `public/v5.js`**, `lesson_scenarios.py` 등이 필요합니다.
5. **환경 변수 `DATABASE_URL`을 삭제/변경하지 않습니다.** 기존 Render 서비스와 GitHub를 그대로 사용합니다.
6. Render Deploys에서 최신 커밋이 `Live` 상태인지 확인한 뒤 브라우저에서 강력 새로고침(Ctrl+Shift+R)합니다.

## 권장 순서로 테스트

1. 기존 개인 코드+PIN 로그인, 기존 수치 유지 확인
2. 퍼즐 → 오답 또는 정답 → `처음부터` → 재채점 가능 확인
3. AI 대국 → 백/흑, 난이도 1 및 5 → 기권 → 대국 복기에서 기록 확인
4. 복기 화면에서 다음/이전 수와 평가 문구 확인
5. 아카데미 → '포크'나 '기물 포획' → 각각 다른 포지션 해결 확인
6. 오프닝 → 흑 실습 → 다음 수 힌트/화살표 위치 확인
7. 기록 초기화는 **테스트 계정으로만** 진행 (복구 불가)

## 기술/검증 범위

- Python/JS 구문 검사를 통과했으며 정적 경로 확인을 진행했습니다.
- 이 작성 환경에서 `python-chess` 설치가 네트워크 차단으로 실패하여 **서버 통합 실행/실전 브라우저 테스트는 미검증**입니다. 새 기능을 모두 실기기에서 동작한다고 확약할 수 없습니다.
- 추가 오프닝은 시작 시 서버 `python-chess`에 의한 합법 수 검사를 거칩니다. 수순에 오류가 있다면 앱 시작 단계에서 예외가 발생할 수 있으므로 배포 로그를 확인하세요.
- 기록이 많은 계정의 전체 수순 분석은 Render 무료 플랜에서 느리거나 요청 제한 시간에 도달할 수 있습니다. 이 경우 다음 단계로 분석 작업 큐와 결과 캐시가 필요합니다.
- 체스닷컴·리체스와 동일한 콘텐츠를 복제하지 않았습니다. 인터랙티브 수업, 전술 테마·단계형 실습, 엔진 복기의 구조적 원칙을 참고하여 자체 구현했습니다.
