# Chess Master Academy v8 — 49문항 실력 진단 · 성장이력 · 3수 메이트

- 기존 v7을 기반으로 만든 누적 패키지입니다. **v7을 GitHub에 아직 등록하지 않았어도 v8 전체 파일만 업로드**하면 됩니다.
- Render 프로젝트와 PostgreSQL `DATABASE_URL` 환경변수, 기존 개인 코드/PIN은 유지하세요.
- v8은 기존 계정 테이블을 변경하지 않습니다. 진단과 변화 이력은 기존 progress JSON에 별도 키로 추가합니다.
- 업로드 전 DB 백업을 권장합니다. 계정 기록 초기화를 하면 v8 이력도 지워집니다.

## v8 기능

1. 7개 영역 × 7문항 = 49개의 서로 다른 FEN 포지션. 분야: 체크메이트 패턴, 킹 안전과 강제수, 전술 계산, 기물 손익, 기물 포획 전술, 오프닝 전개, 킹·폰 엔드게임.
2. 각 분야 안에서 1~7 난이도 단계를 표시. 현재 난이도는 **문제 풀이 시간 가중용 설계 단계**이며 전문가·실제 풀이 데이터에 따른 검증된 난이도가 아닙니다.
3. 답안 제출 이후 서버가 정오답, 모범 수, 걸린 시간과 점수를 반환. 다음 문항 버튼을 눌러야 진행.
4. 49문항 완료 시 50번째 평가: 중급 AI와 백 최대 12수. 일반 연습의 힌트/무르기는 제공하지 않음.
5. 풀이 시간 보정 점수와 난이도 가중 정답률을 종합하고, Stockfish 엔진이 있는 경우 AI 대국 착수의 센티폰 손실 기반 정확도 근사치를 30% 반영. 49문항 70%.
6. 내부 학습 지수 0~1000 및 칭호(입문자/초급자/중급자/숙련자), 이전 평가 대비 변화량, 최대 50회 변화 이력을 저장.
7. 진단 분야별 약점에서 v6 세부 아카데미 과정으로 연결하는 추천 버튼.
8. 퍼즐 아케이드에 **3수 메이트** 챌린지 추가. 출처가 있는 기초 문제 하나의 대칭 변형 4종. 백이 직접 3번 착수하고 흑은 해당 문제의 강제 응수 수순을 둠.

### 점수 해석에 반드시 유의

- 내부 지수 0~1000은 Chess.com, Lichess, FIDE Elo와 아무런 고정 환산 관계가 없습니다.
- 실제 플레이어 집단을 통한 교정/재검사 신뢰도 연구를 수행하지 않았습니다.
- AI 대국은 한 판 전체가 아니라 백 기준 최대 12수 평가 구간입니다.
- `STOCKFISH_PATH`가 없으면 AI 정확도는 계산하지 않고 문제 점수만 산출합니다.
- 재평가 점수는 일시적인 난이도와 시간에 따라 흔들릴 수 있습니다.
- 현재 49문항의 주제·난이도는 자동 생성 및 기존 문제은행을 재사용한 구성입니다. 7개 영역의 완전히 독립적인 고품질 문제은행이라고 보기 어렵습니다.
- 3수 메이트의 한 기본 예시는 Chessonomy의 공개 학습 예시에서 인용한 FEN과 수순을 사용했습니다. https://www.chessonomy.com/blog/mate-in-3-moves

## Render 배포

1. 이 폴더 안 파일 전부를 GitHub `hee908862-tech/chess-master-academy` 저장소의 **루트**에 덮어쓰기. 기존 `public/assets` 폴더도 유지.
2. Render 자동 배포. Dockerfile이 새 `assessment_v8.py`, `v8_server.py`, `mate3_v8.py`를 복사합니다.
3. Render `DATABASE_URL` 변경/삭제 금지. 배포 전 DB 백업.
4. 웹에서 기존 개인 코드로 로그인 후 `실력 진단` 메뉴의 `50단계 새 진단 시작` 선택.
5. 49문항 풀기 → 결과 확인 → 다음 문제 → 50번째 평가 대국 → 프로필 이력 확인.
6. 퍼즐 아케이드에서 `메이트 인 3` 시작.
