# Chess Master Academy v6 — 학습 논리/진단 전면 개편 후보

이 패키지는 기존 GitHub `hee908862-tech/chess-master-academy` 및 Render Docker 서비스에 그대로 업데이트하는 배포 후보입니다. **개인 코드, PIN, DATABASE_URL은 유지**합니다. 업데이트 전에 PostgreSQL 백업을 권장합니다.

## 주요 변경

- 실력 진단: 답안 제출 후 결과 오버레이(정오답 + 모범 착수 적용 포지션) → 사용자가 **다음 문제**를 눌러 진행. 중간에 앱을 닫아도 채점 결과 상태가 서버에 남습니다. 채점 전 정답은 API에 노출되지 않습니다.
- 아카데미: 기존 단일 `answer` 좌표 비교 대신, 서버 `python-chess`로 합법 수와 전술 목표를 검사합니다. 다른 칸에서 똑같은 목표가 성립하면 인정합니다. 잘못된 포크처럼 이동 직후 상대가 기물을 잡을 수 있으면 포크 목표에서 제외합니다.
- 전술을 포크, 핀, 스큐어, 발견 공격, 더블 어택으로 독립 분류. 각 종류별 시나리오를 좌우 대칭을 포함해 **최소 4개** 구성하는 설계입니다. Docker 배포 후 `python validate_v6.py`로 실제 개수와 정답 성립을 검증하세요. 좌우 대칭은 완전한 독립 전술이 아닌 변형입니다.
- 체크, 포획, 전개, 폰 엔드게임 관련 세부 과목 분리. 기존 `대국 복기 습관` 과정은 아카데미 UI에서 제거했습니다. 복기는 대국 기록 메뉴에서 유지됩니다.
- 세부 과정별 완료를 `v6:<과목>` 키에 저장하며, 화면 상태는 완료 직후 서버에서 다시 로드합니다. 기존 데이터 포맷과 별도로 이름 공간을 둬서 과거 수강 이력과 충돌을 줄였습니다.
- 진단 완료 후 결과에 따른 분야별 추천을 아카데미에서 바로 시작할 수 있습니다.
- Dockerfile에 신규 `curriculum_v6.py` COPY 누락을 방지했습니다.

## 제약 및 QA

1. 이번 실행 환경에는 `python-chess` 라이브러리가 없어 **체스판 전체 합법 수 테스트를 실행하지 못했습니다**. `validate_v6.py`를 프로젝트에 포함했습니다. 서버 배포 전에 Docker 환경에서 실행해 결과를 확인해야 합니다.
2. `curriculum_v6.py`는 상호 다른 대표 포지션 2개를 좌우로 미러링해 과목당 최대 4개의 변형을 구성합니다. 4개의 완전한 독립 수업은 아직 아닙니다. 중·고급, 수비적 반례, 희생 검증, 더 깊은 계산 훈련은 더 많은 엔진 검증 문제은행으로 보강해야 합니다.
3. `fork`의 안전성은 공격받는 칸인지와 다중 공격을 검사합니다. 방어된 기물 교환과 깊은 후속 수순은 Stockfish 검증으로 추가해야 하므로 **교육적으로 완전하게 검증된 콘텐츠라고 주장하지 않습니다**.
4. 실력 진단은 기존 5영역×5문항 및 짧은 AI 대국의 예비 추정치이며 공식 Elo나 세부 전술별 엄밀한 숙련도 진단이 아닙니다. 문항별 정오답 기록은 이제 결과에 남습니다.
5. 기존 v5 스크립트 위에 v6를 얹은 호환 패치이므로 장기적으로 레거시 프런트엔드/서버 정리가 필요합니다.
6. JavaScript/Python 구문 검사 및 헤드리스 Chromium의 **정적 페이지 초기화**는 통과했으나, 브라우저 환경의 로컬 서버 주소 접근 제한으로 REST API까지 포함한 실제 두 기기 통합 플레이는 미검증입니다.

## 배포

1. 기존 Render의 PostgreSQL 백업; 환경변수 `DATABASE_URL` 유지.
2. ZIP의 `chess_master_academy_v6` 폴더 내부 파일 전체를 기존 GitHub **저장소 루트**에 업로드. 기존 파일 동일 경로 덮어쓰기.
3. 특히 `server.py`, `curriculum_v6.py` (신규), `Dockerfile`, `public/index.html`, `public/v6.js` (신규)가 핵심. 기존 `exercises.py`, `assessment_v3.py`, `lesson_scenarios.py`, `public/app.js`, `public/extended.js`, `public/v4.js`, `public/v5.js`도 계속 필요합니다.
4. Render에서 Deploy succeeded 확인. **기존 개인 코드 로그인으로 계정 확인**.
5. 가능하면 Docker/local shell에서 `python validate_v6.py` 실행. 전술별 4개 모두 성공인지 확인.
6. 실력 진단 첫 문제 오답 후 정답 재생 → 다음 문제; 아카데미 포크/핀/스큐어/발견 공격/더블 어택; 완료 후 새로고침 없이 완료 표시를 확인.

## 참고한 교육 접근법

- Lichess Learn: 기물 규칙을 직접 플레이하며 학습.
- Lichess Practice: 핀/포크/스큐어/발견 공격 및 폰·룩 엔드게임을 **개념별**로 분리한 실습.
- Chess.com Lessons: 개념 설명 → 인터랙티브 실습 → 숙련 확인.

내용과 문제 자체를 복제하지 않고 학습 구조와 상호작용 원칙을 참고했습니다.
