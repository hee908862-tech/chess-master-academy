# 정답 후 메이트 해설 및 검사 계약 갱신

기준 PR #4 head `5d1522cf84d9608ff2c839d45a5f0f0b1fedee2d`의 모든 수정을 보존한다. main 병합·배포 및 운영 계정/기록/문제은행 변경은 수행하지 않는다.

## 사용법

N수 메이트 퍼즐의 수순을 해결하거나 진단 문항을 맞히면 **메이트 해설 열기 / 닫기**가 나타난다. 별도 보드에서 상대 왕과 체크 기물을 보고, 왕 주변 칸 또는 아래 설명 버튼을 선택한다. 선택 칸을 통제하는 기물 모두에 `통제` 라벨이 붙고 좌표·기물 목록도 표시된다. 색만으로 구분하지 않으며 터치·키보드 버튼을 지원한다. 해설은 원래 플레이어 방향을 유지한다. 다음 문제/새 문제에서는 해설을 지우며, 저장된 완료 퍼즐이나 진단 피드백은 재접속 후 해당 메뉴에서 다시 볼 수 있다.

## 구현과 정확성 경계

- `mate_explanation.py`는 유효한 보드, 체크 및 실제 `is_checkmate()`/합법 대응 0개를 확인한다. 왕 이동뿐 아니라 포획·차단을 포함한 모든 합법 대응이 없는 경우만 메이트로 설명한다. 스테일메이트, 단순 체크, 미종료 위치는 해설 불가 안내를 반환한다.
- 왕의 8개 주변 후보마다 보드 밖/수비 측 점유/공격 측 통제/왕 인접을 구분한다. 원래 왕 칸과 목적지의 포획 기물을 제거한 가상 보드에서 공격자를 계산하므로 기존 왕이나 잡히는 기물이 가리던 공격선도 반영한다. 수비 기물 점유 칸의 공격자 분석은 실제로 둘 수 없는 가상 이동임을 안내한다. 복수 공격자와 더블 체크를 모두 보존한다.
- 퍼즐은 실제 마지막 착수 결과를 사용한다. 인정된 대체 메이트·퀸/룩 승격은 사용자가 둔 결과를 그대로 설명한다. 중간 정답 착수, 오답, 힌트/정답 공개에는 최종 해설을 제공하지 않는다.
- 진단은 첫 착수 판정이므로 정답 후 별도 보드에서 원본의 합법 수순을 적용해 최종 메이트를 보여준다. 실제 진단 보드·문항 번호·시도 기록을 그 최종 위치로 진행시키지 않는다. 즉시 대체 메이트도 인정하고 실제 제출 수의 결과를 사용한다. 채점 전 공개 문항에는 정답 수순이나 해설을 넣지 않는다.
- 해설 보드는 게임 입력을 보내지 않는다. 열 때 원래 보드의 프리무브를 취소하며 기존 힌트·직전 수 강조와 독립적이다.

**부분 지원/미지원:** 원본이 메이트 전에서 끝나거나 수순이 유효하지 않으면 최종 위치를 추측하지 않는다. 비종료 대체 정답의 별도 수순이 없으면 해설 불가로 안내한다. 엔진으로 모든 방어 분기를 탐색하거나 N수 강제 메이트 자체를 증명하는 기능은 추가하지 않았다. 진단의 원본 최종 위치는 검증된 한 수순의 결과이며 실제로 끝까지 사용자가 플레이한 기록이 아니다. 운영 PostgreSQL·실물 모바일/Safari 검증은 별도다.

## 구형 검사 갱신

`test_v81_regression.py`는 옛 영역명 문자열 대신 지원 7영역, 각 영역 7난이도, 중복 없는 실제 49문항, 원본 태그 매칭, 정답 비공개를 검사한다. 가짜 import 모듈을 제거하고 실제 의존성을 사용한다. 첫 assert 뒤에 가려져 있던 점수 테스트의 10착수 정확도 기대를 수정하여, 현재의 12개 유효 착수 기준과 11개일 때 미측정을 함께 검사한다. 기존 다른 계약은 유지하며 각 구조 검사 결과를 출력한다.

`test_v3_static.py`는 script가 정확히 2개여야 한다는 조건을 필수 모듈의 존재·의존 순서·중복 실행 금지·로컬 파일 존재 계약으로 바꾼다. 이후에 있던 기물 자산·UI 바인딩·API 경로 검사도 모두 실행한다.
