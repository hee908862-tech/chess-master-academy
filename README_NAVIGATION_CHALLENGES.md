# 기능 탐색과 선택형 퍼즐 도전

기준 main `c4f7d3f2b6f9c58780e37ec9345c2d7f452653e4`. 독립 검토용 수정이며 이 작업에서는 병합·배포·운영 계정 변경을 하지 않는다.

## 변경 범위

- 기존 `audit-ui.js`의 PC/모바일 메뉴에 하나의 아카데미 하위 메뉴를 추가했다. 클릭/Enter로 열고 Escape/닫기/바깥 클릭으로 닫는다. 기초 배우기·전술 훈련·복습·이어하기가 기존 공통 `tab()` 경로를 사용한다. rules-first 추천과 기존 직접 탭 호출도 보존한다.
- 아카데미 상단에 목적별 선택과 현재 경로를 표시하고 저장된 전술 과정·기초 복습·진단·훈련을 구별한다. 주요 10개 화면의 상단에 같은 ‘사용 방법’ 버튼을 두었다. 안내는 DOM만 변경하며 학습 세션 생성·정답 힌트·기록 변경 API를 호출하지 않는다.
- 훈련실과 오프닝에 보드/해설/행동·저장 도구 바로가기를 제공한다. 모바일 훈련 해설을 기본 펼침으로 하고 오프닝 탐색의 다음 수 해설을 보이게 했다. 혼자 풀기/검증의 정답 가리기는 유지한다.
- 공통 승격 선택창에 Escape·취소 버튼·바깥 클릭과 키보드 포커스 순환을 추가했다. 취소는 서버 착수를 보내지 않으며 도전/복기/오프닝 보드에서 다시 선택할 수 있다.
- 복기 보드 아래 ‘여기부터 다시 두기’는 기존 `BoardStudy`를 그대로 사용한다. 원본 시작부터 선택 반수까지의 이력으로 분기해 차례·권리·반복 조건을 유지한다. 엔진 예산을 바꾸지 않았다. 분기는 임시 메모리이며 원본 복귀·화면 이동·새로고침 시 원본 기보/통계에 저장되지 않는다. 영구 분기 편집기는 추가하지 않았다.

## 선택형 퍼즐 연속 도전

일반 퍼즐을 기본 화면으로 유지하며 ‘연속 도전·이어하기’로 전환한다. 시간제한 없는 10문제, 목숨 3개만 구현했다. 타임어택·순위표·Elo는 추가하지 않았다. 입문/중급/고급의 기존 레이팅 범위에서 서로 다른 10문제를 뽑는다. 부족하면 503으로 안내하며 가짜 문제로 대체하지 않는다.

기준 수순 완주 10점, 실제 정답 힌트 후 완주 5점이다. 다른 합법 수/건너뛰기는 게임 목숨만 1개 소비한다. 규칙으로 확인한 즉시 메이트 대안은 인정하지만 나머지 대안의 우열은 미검증이다. 이 제한을 시작 전에 밝힌다. 불법 수는 점수·목숨을 바꾸지 않는다. 일반 사용법은 도움 사용으로 세지 않는다.

`puzzle_challenge_v1`이라는 별도 progress 필드에 세션·문제 스냅샷·revision·완료 결과를 저장한다. 클라이언트는 점수를 제출하지 않는다. 서버가 합법성/수순/힌트를 검증하며 기존 DB 트랜잭션의 필드 CAS로 동시 변경을 막는다. 매 전이의 고유 write_id로 내용이 같은 동시 요청도 하나만 성공하도록 했다. 이미 처리한 revision/종료 세션은 409다. 대국·진단·일반 퍼즐·추천 훈련 크레딧에 합산하지 않는다.

탭 이동/새로고침 후 같은 계정에서 불러올 수 있다. 응답 불명일 때 자동 재전송하지 않고 저장 상태 조회를 요구한다. 완료 결과에서 제출한 수·정답 도움 여부·기준 수순 보드를 확인한다. 종료 전 정답 전체를 반환하지 않는다. 종료하지 않은 현재 문제는 직접 마칠 때 채점하지 않으므로 완료 복습에 포함되지 않는다. 다른 계정의 결과는 404다. 완료 이력은 삭제하지 않으며 장기 저장량 정책은 별도 과제다.

## 오프닝 콘텐츠

기존 27강/6계열/107개 주요 해설을 보존하고 **28강을 추가해 55강/11계열/192개 주요 해설**이 됐다. 기존 CC0 참고 수순 3,865개는 그대로이며 강의와 구별한다. UI 수치는 실제 catalog에서 계산한다.

|---|---:|
| 런던 기본·Qb6·g6·조기 c5 대응 | 4 |
| 조바바 런던 교환·a6·c5 대응 | 3 |
| 토레·콜레·콜레 주커토르트·베레소프·트롬포프스키 | 5 |
| 스카치·페트로프·비엔나·포 나이츠 | 4 |
| 스칸디나비안·피르츠·알레힌 | 3 |
| 킹스/님조/퀸스 인디언·카탈란·그륀펠트·잉글리시2·레티·더치 | 9 |

교육용 대표 수순이며 강제 수순, 최신 최선 수, 인기 순위·점유율을 주장하지 않는다. 각 강의의 주요 착수와 상대 의도·구조·끝 위치의 다음 계획은 독자 작성했다. 해설은 선택 강의의 실제 등록 위치에서만 적용하고 미등록 분기에 종료 계획을 표시하지 않는다. 전치는 기물/차례/캐슬링/합법 앙파상 권리가 같은 위치로 판별한다.

조사 출처는 [London System](https://www.chess.com/openings/London-System), [Torre](https://www.chess.com/openings/Torre-Attack), [Colle](https://www.chess.com/openings/Colle-System), [Trompowsky](https://www.chess.com/openings/Trompowsky-Attack)의 공개 개요와 부모 검토자가 확인해 전달한 각 공식 `/openings/` 페이지 및 대표 수순이다. 원문 문단·유료 강의·그림을 복제하지 않았다. 이름과 기보 사실은 저장소의 [CC0 참고 출처](data/openings/SOURCE.json)와도 구별해 사용했다. 수순 합법성과 해설이 가리키는 폰/핀/전치 조건은 python-chess 및 회귀로 확인한다. 엔진이 모든 강좌를 최선 수로 인증한 것은 아니다.

## 환경과 검증

검사는 임시 SQLite 계정, 지정된 loopback PostgreSQL17 `cma_predeploy`, 1CPU/512MiB 로컬 Docker에서만 수행한다. 운영 데이터는 읽거나 변경하지 않는다. 최종 전체386개, PostgreSQL16개, Docker HTTP4종 및 PC/모바일 각10화면 도움말 검사가 통과했다. Python90개 AST/JavaScript22개 구문 검사도 통과했으며 전용 타입·린트는 설정이 없어 별도 미실행이다. 실행 결과·중간 실패와 수정·화면은 [검증 증거](docs/qa-navigation/README.md)에 기록한다.

참고 메뉴 이미지 Library ID 3개는 prepare_materialize가 서명 전송 URL을 발급했으나 이 실행 환경의 다운로드가 모두 `URLError: Tunnel connection failed: 403 Forbidden`으로 차단됐다. 스킬 목록은 비어 있고 체크아웃/워크스페이스 `.agents/skills`도 없었다. 이 이미지를 직접 본 것으로 주장하지 않는다. 부모가 직접 확인한 계층형 탐색 요구를 사용해 구현했으며 본 앱의 새 화면은 로컬 실제 Chromium 이미지로 확인했다.

물리 모바일·Safari·장기 학습 효과·타임어택·모든 동등 최선 수·영구 분기 보관은 미지원 또는 미검증이다. 기존 보안 유예, 진단 비교 기준, standard5/gentle/7일 gate는 변경하지 않았다.
