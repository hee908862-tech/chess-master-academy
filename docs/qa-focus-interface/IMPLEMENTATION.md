# 집중형 UI 구현 범위와 검증 원칙

기준: main 931fc3d0d15ac6a8249d7f044d595dff0e25614b.
단계1 원격 체크포인트: ecc78adf9d1682ffedb6f12d6804d391dd7c917f (관련31통과).

- 기초: 기존 지시/판정/저장/선택지/다음 DOM을 보드와 한 학습 패널로 재배치. 짧은 이유와 상세 펼침, 기존 시범/승격/목록 착수 보존.
- 대국: 기존 game-focus 배치와 모든 조작 재사용. 규칙/시계/프리무브/세션 로직 변경 없음.
- 공통 피드백: 서버 판정/저장 문장을 그대로 유지하며 해설은 짧은 개요+상세 펼침. 정답 공개 조건은 기존 컨트롤러가 결정.
- 훈련: 현재 훈련과 선택/저장 활동/오답노트/능력지도/최근 기록을 구분. 학습 경로와 현재 개념은 활동 패널에 유지. 패널 전환만으로 tab/노출/저장 요청하지 않음.
- 오프닝: 강의/모드/방향 선택을 접을 수 있는 명시적 패널로 이동. 초기에는 열림. 보드/이동/북마크/레퍼토리 유지.
- 퍼즐: 주제/난도/출제/카탈로그 오류를 선택 패널로 구분. 도움/정답/다음과 기존 카탈로그 준비 잠금 보존.
- 복기: 기보 선택 전 분기 조작을 숨기고 선택 후 기존 조작 제공. 원본/분기 상태 모델 변경 없음.
- 내 정보: 성장·활동 기록 / 표시·학습 설정 / 계정 연결 / 기록 관리의 공개 UI 경로. 개인정보/토큰/세션 ID는 URL에 넣지 않음. 초기화 버튼은 유지하되 작업 중 실행하지 않음.

## 게스트 예제
기존 foundation_content의 비숍, 나이트, 한 수 체크메이트 3개 위치를 사용한다. build_guest_examples.py가 python-chess로 초기 합법 수 전부와 도착 FEN/메이트를 생성한다. 일반 체스 대국 엔진이나 진단이 아니라 한 수 교육 예제이다. 합법적인 다른 수를 나쁜 수로 단정하지 않고 이번 목표와 구분한다. 메이트 예제는 모든 즉시 메이트 대안을 인정한다.

public/guest-examples.json은 공개 정적 교육 자료다. 클라이언트 결과를 공식 성적으로 신뢰하지 않으며 서버 기록/API 쓰기/자동 이관은 없다. 도움 사용은 화면 내 일시 표시이고 재시도 성공도 정식 수료나 무도움 실력 증거가 아니다. 새로고침/나가기는 체험을 비운다. 계속 배우기는 기존 인증/기초 진입을 사용한다.

## 증거 구분
원시 로그는 head/실행 명령과 함께 보존한다. 패널 변경으로 이전 검사 클릭 경로가 바뀌면 새 공개 UI 경로를 거쳐 같은 판정/기록 assertion을 유지한다. 실행 중 소스 변경은 하지 않는다. Docker COPY/import/static 검사와 실제 이미지 빌드/PG는 별개다. 현재 루트 디스크 여유0으로 실제 Docker/PG는 미실행이며 사용자 자료나 DB를 삭제하지 않는다. 실제 모바일 기기/초보자 사용성 검사는 로컬 반응형 Chromium 검사와 구분한다.

## 추가 독립 리뷰 반영
- 기존 저장 훈련의 이어하기도 공통 선택 상태를 닫는다. 패널 복귀는 새 훈련/노출 쓰기를 보내지 않는다.
- 학습 복습 간격은 설정 화면에서 현재 계정 값을 별도 조회한다. 조회 전에는 입력·저장을 잠그고 실패 재조회, 계정 변경 후 늦은 읽기/저장 응답을 무시한다. 같은 화면 재진입은 진행 중 저장을 취소하지 않는다.
- 게스트 비숍의 합법 대안 c1→d2는 목표 미달임을 알리고 d2로 키보드 포커스를 돌린다. 추가 focus 주입 없이 c1로 돌아가 g5까지 연속 입력하는 검사를 포함한다. 성공은 결과/다음 행동 영역으로 이동한다.
- 교육/레퍼토리의 범위·사용법·저장 조회, 누적 기록, 상세 해설을 각각 접을 수 있다. 현재 목표와 판정/다음 행동은 유지한다. 재배치를 공통 모션 전 동기화하고, PC 보드와 판정 패널은 같은 행의 두 열을 사용한다. 모바일에서는 보드 다음 판정/행동이며 긴 콘텐츠는 스크롤한다.
- 기존 퍼즐 새 출제 실패의 상태 재조회/invalidate 계약은 변경하지 않았다. 선택 패널은 성공한 새 세션에만 접히며 실패하면 출제/재시도 접근이 유지된다.

58행 대응표의 '추천 위치'는 설계이고 '이번 구현의 연결 지점'이 실제 적용 범위다. 대국·진단·도전의 기존 보드 중심 구조/모드별 핵심 조작은 재사용한다. 모든 화면을 무스크롤로 보장하지 않으며 특히 좁은 레퍼토리의 긴 조작은 아래로 스크롤한다. 새로운 학습 엔진·진단 모델·이력 통합 저장은 없다.
