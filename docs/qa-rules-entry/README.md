기준 main: b9de974e30f110d7db39bdab87180c07965ba4a4. 운영 계정은 변경하지 않았다.

룰 완료 버튼이 진단 탭만 열어 기존 결과가 입문 시작을 숨겼고, 서버와 입문 재확인 버튼도 gentle에 표준5개 gate를 적용했다. 수준 선택의 마지막 버튼에서 별도 시작 안내를 표시하며 gentle만 gate에서 제외했다. 표준12/24는 그대로 잠기고, 진행 중 다른 진단은 교체하지 않고 이어하기를 제공한다. 입문 완료 화면은 남은 표준 과제 수와 기존 추천 이어가기를 안내한다. 도움말·튜토리얼도 수준 선택, 4단계 첫 안내의 범위, 최대6문항 입문과 표준12/24 흐름에 맞췄다.
