# 공통 보드 체크·모션 (2단계)

## 범위와 보존

PR25 병합 main `140f97760a1b1c9935612219fe1c92b865bcdf71` 기준. 공통 drawBoard에 실제 표시 배치의 체크 표시(빨간 테두리+체크 라벨+접근성 이름)를 적용한다. 핀된 공격도 계산하고 python-chess의 공격 판정과 대조한다. 체크메이트/스테일메이트 결과는 기존 서버 판정을 유지한다. 체크 표시는 정답/추천 수를 표시하지 않는다.

이동은 명시 UCI와 전후 배치의 정확한 일치가 있어야 한다. 캐슬링 두 기물, 앙파상, 승격, 포획, 역방향 복원 및 최대 두 반수의 연속 이동을 처리한다. 수순이 없거나 두 반수를 넘는 점프는 즉시 표시한다. 서로 다른 퍼즐·강좌 배치 차이로 이동을 추정하지 않는다. 기존 대국 단일 기물 모션은 공통 구현으로 대체해 이중 실행하지 않는다.

화면/계정 변경, resize, scroll, 문서 숨김, reduced motion 변경, 새 위치/연속 탐색은 모션을 취소한다. 서버 결과와 입력/시계 갱신은 애니메이션 종료를 기다리지 않는다. 모션은 pointer-events:none이며 접근성 트리에 중복 기물을 추가하지 않는다. 같은 위치의 조작 UI 재렌더는 이동을 불필요하게 중단하지 않는다.

저장 스키마/채점/도움 기록/인증/시계 규칙은 변경하지 않는다. foundation/learning/challenge/undo 응답에 이미 적용·제거된 UCI만 표시 메타데이터로 추가했다. 운영 계정에 접근하거나 쓰지 않았다. 대국의 늦은 실패 응답도 현재 요청·계정일 때만 로컬 상태를 되돌리도록 한정했다.

## 연결

- 대국 본인/AI 착수와 무르기, 전술 응수.
- 기초 실제 착수와 읽기 전용 앙파상 시범.
- 훈련 착수/무르기/복기 프레임, 진단 착수/해설, 교육 착수.
- 오프닝·복기 분기 BoardStudy, 원본 기보의 인접 수 탐색.
- 레퍼토리·퍼즐 도전 실제 착수, 결과 복기, 로그인 전 룩 체험.

전체 배치/높이/안내 우선순위를 개편하는 3단계는 별도다. 현재 오프닝의 긴 위쪽 선택 영역은 이번에 축소하지 않았다.
