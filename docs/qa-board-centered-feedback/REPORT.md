## 한계

Docker/PostgreSQL 최종 검증은 루트 디스크 여유0 제약으로 미실행. DB/이미지 삭제로 해결하지 않았다. 원격CI는 최종 조회 결과를 별도 기재한다. 운영 브라우저·물리 모바일·실제 초보자 학습 효과·접근성 인증은 수행하지 않았다.
