# 오프닝 기록 복원 안내 후속

기준 main: `fb7fbef15a67d6c1257c5e42e599e44c3731a949`.

## 실제 재현과 판단

운영 QA 정정과 동일하게 로컬 Chromium·임시 SQLite 계정에서 확인했다. 기존 ‘다음 수’는 이미 방문한 수의 redo다. 초기 위치에서 누르면 같은 위치를 다시 조회한다. 해설 응답을 의도적으로 지연시키면 공통 자유 분기 안내가 잠깐 나타나고 후보가 비지만, 응답 후 해설과 후보가 정상 복원된다. 지속적인 보드/수순 결함이나 이벤트 충돌은 재현되지 않았다. `observe_baseline.py`는 수정 전 main에서 실행한 재현 코드이며 `baseline.log`의 1개 통과는 이 관찰을 뜻한다. 수정 후 회귀 테스트가 아니다.

## 최소 변경

- 오프닝의 ‘다음 수’를 ‘되돌린 수 복원’으로 바꾸고 기록 끝·보드 요청 중·비활성 상태에서 비활성화한다. ‘이전 수’도 처음 위치와 요청 중에는 비활성화한다.
- 새 착수는 보드나 탐색 모드 후보에서 선택한다는 설명을 추가하고 사용 방법을 일치시킨다.
- 강의 해설 응답을 기다리는 동안 오프닝 해설 로딩 안내를 표시한다. 참고 수순의 기존 안내와 종료 상태는 유지한다.
- 공통 BoardStudy 이동/redo, 분기 선택, 서버, 엔진, 북마크 저장 로직은 변경하지 않았다.

## 검증 범위

**최종 관련 검사 25개 통과(51.22초), 실패 0개.** 기존 TestClient/httpx 사용 중단 예정 경고 1건이 있다. `tests/test_study_browser.py`, `tests/test_study.py`의 최종 결과는 `regression.log`에 보관한다. Chromium 390/1280px의 새 회귀는 초기/끝 비활성화, 지연 응답 중 문맥 안내, 이전→복원 보드·해설 일치, 다른 착수 후 redo 폐기, 혼자 풀기 정답 가림 및 계정 상태 불변을 검증한다. 기존 검사는 저장·복원 경합, 원본 복기 보존·엔진 취소, 합법성·특수 수·55강 및 참고 수순을 확인한다.

변경 JS 2개 Node 구문 검사, 변경 Python 테스트 AST, `git diff --check` 통과. 전용 타입/린트 검사 및 전체386/PG16/Docker 검사는 이번 작은 UI 후속에서 재실행하지 않았다. 과거 결과를 이 head의 결과로 주장하지 않는다. 물리 모바일·Safari·운영 브라우저는 미실행. 운영 데이터·북마크·계정 변경, 병합, 배포는 수행하지 않았다.
