# 배우기 선택/실습 분리 검증 (PR24)

기준 main: `97965f5e054094d251a80e2ac7cdf381392fd9cb`.
최신 검증 코드 head: `bcc9923bb3c6e3e3cdbcc9eaaedb3b01aea59d94` (2차 독립 검토 보완 포함).

## 요구사항과 반영

- 홈의 펼친 기초 배우기 카드: 1클릭으로 저장된 기초 실습 또는 시작 목록. 통계는 기초·이어하기 뒤쪽. 실제 저장 활동이 없는 추천을 이어하기라고 부르지 않는다.
- 배우기 허브: 기초/전술/위협·계획·종반/맞춤 훈련/퍼즐/오프닝 6개와 별도 저장 활동. 메뉴에도 같은 주제 제공. 허브에는 보드가 없다.
- 기초/전술/교육: 목록과 활성 실습을 분리한다. 기초 실습은 추천·전체 목록을 숨기고, 전술은 31개 카드 아래에 실습을 붙이지 않는다. 목록 복귀 시 선택 버튼의 포커스와 스크롤을 복원한다.
- 허용한 화면/주제만 URL hash에 표시한다. 계정/세션 식별자는 넣지 않는다. 뒤로/앞으로/새로고침은 저장 조회로 복원하며 새 시도를 생성하지 않는다.
- 기존 tab 래퍼를 실제 외부 화면 이동 시 호출하고, 배우기 내부 목록/실습 이동은 독립 UI 경로로 처리한다. 메뉴만 열고 닫는 것은 실제 활동 이탈과 구분한다.
- `hidden`/`inert`로 비선택 영역을 포커스와 보조기술에서도 제외한다. 모바일 실습의 하단 탐색을 문서 흐름에 배치하여 보드를 덮지 않는다.

## 파일과 경계

`learning-navigation.js/css`는 공통 UI 경로/구획/포커스 담당, `foundations.js`, `v9.js`, `education.js`는 기존 상태 조회 및 명시적 시작 후 UI 경로 연결만 보강한다. `journey.js`, `first-visit.js/css`, `feature-guide.js`, `audit-ui.js`, `index.html`은 홈 순서/명칭/기존 메뉴 닫기 경로를 연결한다.

백엔드, 저장 모델, 채점, 인증 정책, 의존성은 변경하지 않았다. 기존 저장된 대국/학습을 자동 종료하거나 초기화하지 않는다. 훈련실 내부 선택/기록 분리는 제외했다. 진입 때 발생하는 `/learning/exposure` POST의 의미를 단순 UI 변경으로 바꾸지 않기 위해서다. 새 허브와 다른 학습 주제만 둘러볼 때 POST 0을 검사한다. 내 기록의 성장/활동/계정 설정 중첩은 남아 있으나 본 PR과 무관한 전면 개편은 하지 않았다.

## 독립 검토 보완

- 교육 활성 실습→목록→다른 수업 시작이409를 반환하고 이어하기까지 비활성화하는 현상을 실제 Chromium에서 재현했다. 활성 시도가 있으면 새 시작을 비활성화하고 현재 실습을 이어가거나 그 실습에서 명시적으로 결과를 보관하도록 안내한다. 실패 후 단순 이어가기 이동은 가능하다. 자동 보관/중단은 하지 않는다.
- 전술 첫 착수 응답 지연→다음 수 예약→허브 이동→응답 도착 시 숨겨진 보드가 두 번째 move POST를 보내는 현상을 재현했다. 실습을 실제로 떠날 때 로컬 예약을 취소하고, 응답 이후 실행에도 보드 가시성을 확인한다. 첫 서버 결과는 보존한다. 메뉴 열기/Escape만으로 예약을 지우지 않는 검사도 포함한다.
- 전술은 공개 catalog의 theme/level만 URL UI선택으로 유지한다. 로그인/새로고침 후 선택을 복원하며 자동 시작하지 않는다. 저장된 과정이 선택한 과목/난도와 다르면 끌어오지 않는다. 과거 계정의 session ID를 전달하지 않는다. 잘못된 과목/난도는 목록으로 돌아간다.
- 교육 게스트에는 계정 연결 CTA를 제공하고 로그인 후 교육 목록을 보여준다. 조회만으로 교육 시도를 만들지 않는다.
- 집중18개 통과(기존 집중12+후속6). 후속 추가2개(다른 저장 과목/200%확대·긴문장)를 포함한 후속8개+관련 교육/메뉴31개 통과. 일부 검사가 중복되므로18+31을 고유 검사 수로 합산하지 않는다. 로그는 `review-extended-31.log`.

## 2차 독립 재검토 보완 (bcc9923)

코드 `bcc9923bb3c6e3e3cdbcc9eaaedb3b01aea59d94`는 다음 누락 조건을 보완했다. 이전559통과가 이 조건까지 검증했다는 뜻은 아니다.

1. 교육 답안이 서버에 저장되고 응답만 지연된 상태에서 Home으로 이동한 후 교육에 복귀하면, 기존 데이터 캐시를 신뢰하지 않고 GET으로 진도를 다시 확인한다. 해당 정확한 시나리오를 수정 전 실패로 재현하고, 최신 진도 및 늦은 이전 응답 무시를 검사했다.
2. query가 없는 bare `#learn/tactics/practice`도 catalog await 이전에 계정/탐색 세대를 캡처한다. 대기 중 허브 이동 후 catalog 응답이 와도 허브에 머문다. 수정 전 실패로 재현했다.
3. 과목 복원은 이동 callback 없이 과목/난도를 함께 적용하고 URL 정규화는 replace만 사용한다. A/비기본난도→목록→B→Back2회→Forward2회에서 history 길이와 Forward를 보존한다. 같은 과목의 다른 난도 캐시도 재사용하지 않는다.
4. 교육 목록 렌더 후 활성 lesson article에 포커스와 스크롤을 복원한다. 비활성 시작 버튼이나 일반 제목을 복귀 대상으로 쓰지 않는다.
5. 홈의 기초 활성 중복3개를 하나의 기초 카드(진도+이어하기)로 합친다. 실제 다른 진단/훈련이 우선 활동이면 해당 활동 카드는 함께 유지한다. 신규/기초활성/진단동시활성의1클릭 진입·저장값 불변과 캡처를 확인했다. `home-distinct-{new,basics,diagnosis}-390.png`가 최신 세 상태이며 이전 `home-390.png`의3중 중복을 대체한다.

검사: 정확한2개 시나리오는 수정 전2실패, 수정 뒤 기존후속 포함10통과. 관련50개는49통과/1실패(기존 중복 버튼 좌표를 읽던 검사); 표시 대상을 새 기초 버튼으로 수정하고 추가 난도 캐시 검사를 포함해17통과. 원래 화면 내 버튼 배치 검증은 유지했다. 최신 전체 회귀는 별도로 기록한다. JS 구문/diff 검사 통과.
