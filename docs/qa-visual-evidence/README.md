## 누적 기준의 근거와 한계

`profile-evidence-v1`: 평가하는 6분야 전부, 각 분야 기초4+응용4 이상, 분야별8 이상, 전체48 이상을 **AND**로 검사한다. `skill_index.EVIDENCE_POLICY`가 버전과 기준을 명시한다. 48은 제품 설계 가정이며 IRT 교정/모집단 신뢰도/정확도 보장/1점 정밀도 주장이 아니다. 충족 후에도 내부 지표는 잠정이다.

현재 문제은행의 분야별 고유 문제 ID 수(기초600–1199 / 응용1200–1799):

| 분야 | 기초 | 응용 |
| --- | ---: | ---: |
| 메이트 | 4,623 | 4,807 |
| 다중 수 계산 | 10,449 | 13,459 |
| 포획·교환 | 4,664 | 6,293 |
| 방어 | 601 | 953 |
| 승격 | 898 | 942 |
| 종반 전술 | 1,892 | 1,583 |

같은 문제가 여러 분야에 속할 수 있어 표의 수를 독립 문항 수로 합산하면 안 된다. 실제 완료 검사는 문제 ID와 전체 수순의 국면 겹침을 중복 제거한다. 실제 은행에서 6분야×2난도×4개를 겹침 없이 구성하는 검사도 추가했다. 이것은 특정 사용자의 남은 미노출 후보 보장이나 분야 전체 대표성 검증이 아니다. 전략/계획·일반 종반 전체는 미측정이다.

새 평가 조건/같은 역량 버전/같은 문제은행의 종합·간이·분야별 완료 세션만 근거에 포함한다. 특정 하위 주제만 고른 부분 진단은 대표성 때문에 누적 충족에서 제외하되 자기 결과·추천 훈련은 유지한다. 도움/기노출/재시도/중복/부분 수행/건너뛰기/미확정 대안은 유효 문항 아님. 엔진 실패를 오답으로 계산하지 않는다. 중단 세션은 완료 전 제외한다. 앱 밖 노출은 알 수 없다. 미확정 문항을 제외한 횟수 충족이 선택 편향이나 난도 편향을 해소하지도 않는다.

`ceil(부족 문항/24)`는 종합 진단의 **최소 분량**만 의미한다. 난도·분야별 부족, 실제 유효 응답, 사용자별 문제 부족, 기존 훈련 게이트 때문에 실제 회차는 확정하지 않는다. 후보 부족 시 기존 409 안내와 데이터 보존을 유지한다. 누적 지표를 위해 과거 점수를 새로 계산하거나 평균내지 않는다.

## 복기 분석

제출 전에는 분석 API에 접근 불가. 인증된 소유자의 제출 완료 문항 또는 저장 결과에서만 서버가 원래 FEN/합법 수순으로 프레임을 재구성한다. 착수권·캐슬링·앙파상·시계 필드를 보존한다. 조회/재생/분석은 응답·채점·저장을 쓰지 않는다.

분석은 버튼을 눌렀을 때만 기존 공유 엔진 예산으로 최대0.2초/깊이14, 최소깊이10을 사용한다. 백 기준 cp, ±0.50 이내를 ‘대등’으로 표시하는 UI 기준을 명시한다. 막대는 ±10폰에서 포화하며 승률이 아니다. 메이트/스테일메이트는 별도 규칙 결과, 미분석/불충분/사용중/실패는 대등으로 표시하지 않는다. 규칙상 효과를 설명하며 학습자 심리나 근거 없는 전략적 의도를 생성하지 않는다.

## 미검증과 접근 제한

첨부5장 Library 참조는 확인됐으나 지원 materialize가 각 파일에서 `library file transfer failed: download failed` (exit1)로 실패했다. 소비 환경 경로로 허용된 한 번의 지원 재시도도 동일하여 중단했다. **이 실행 환경은 원본 픽셀을 열지 못했다.** 부모가 5장을 실제 확인했으며 배포 후 원본 대조를 독립적으로 담당한다. 아래 구현 캡처는 로컬 신규 테스트 화면이지 원본 대조 완료 근거가 아니다.

운영 UI는 이 실행 환경에서 기존 CONNECT proxy403 차단 이력이 있어 재시도/우회하지 않는다. Render Live API 확인과 운영 UI 성공을 구분한다. 실제 모바일 기기/초보자 관찰은 미실시. 기존 계정 조회 지연은 이번 수정으로 해결했다고 주장하지 않는다.

같은 점수·평가·역량·문제은행 버전, 안내 조건, 진단 모드와 선택 범위에서 두 결과 모두 비교 가능한 분야만 이전 파선/빈 원으로 겹쳐 본다. 기본은 현재 결과이며 체크박스로 과거를 선택한다. 점수 차이가 성장 확정을 뜻하지 않는다. 새 누적 점수를 만들거나 과거 점수를 평균내지 않고 원래 회차 점수와 누적 근거 카운터를 분리했다.

실제 Stockfish 검사와 로컬 Chromium 조작, 소유권/제출 전 분석 차단, 기존 진행 세션 보존, 중복 근거 제외, 앙파상·승격·선택 취소, 느린 응답·오류 복구, 키보드·확대·화면 회전, 패키징 스테이징을 포함한다. 합성 과거 레이더 자료 및 일부 지연/실패 응답은 통제 fixture이며 실제 사용자 기록이나 운영 장애 재현으로 주장하지 않는다.
