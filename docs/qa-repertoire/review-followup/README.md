# PR17 독립 검토 후속

검증 소스: `4b3313d6f7f23b249caf3779933b8ce213328ad2`. 이전 전체442/PG17/Docker 결과는 `99c4430`이며 이번 후속에 재사용하지 않는다.

- 신규15개 심화 설명은 백 차례 위치에 한정됨을 명시했다. 흑의 기존 해설·규칙 사실과 구분한다.
- 누적/첫 복습은 레슨 단위 백·흑 통합이다. 새 첫 결과에 실제 색을 저장하며 기존 색 누락은 미기록으로 표시하고 추정하거나 수정하지 않는다.
- 새 시작/재시도는 현재 및 새 시도의 종료 보관 자리까지 사전 확보한다. 정규64개 한도에서 신규 시도는 막되 종료·조회·탐색 복귀는 유지한다. 이전 결함의64개+활성 시도는 기존64개를 그대로 두고 해당 시도1개만 retained 슬롯에 옮겨 종료한다. 자동 삭제/초기화하지 않으며 신규 시도 확대도 아니다.
- 256행/1MiB 경계에서 종료는 새 입력행 없이 수행한다. 종료 메타데이터에만 기존 크기 대비 최대1KiB를 허용한다. 그 뒤 새 쓰기는 원래 상한을 따른다.
- request는 실제 성공만 true를 반환한다. finish→start와 hint→닫기는 계정/token·세대·화면/열림 상태가 유지될 때만 후속 동작을 실행한다.
