# 기초 직접 연습: 자동 예시와 적은 버튼

대상은 현재 기초 직접 연습 62개입니다. 유효한 예시가 있는 규칙 45개는 레슨 선택, 이어하기, 새로고침, 화면을 나갔다 돌아오는 진입마다 자동 소개합니다. 단순 이동 17개에는 빈 팝업을 만들지 않습니다. 별도 저장된 이전 기초 과정(`foundation_v1`)과 다른 기능의 화면은 변경하지 않습니다.

기존 버그는 설명 단계 및 세션별 열람 캐시로 자동 소개를 제한하여, 이미 진행한 세션에서는 설명이 나오지 않는 것이었습니다. 이제 화면 진입과 렌더/저장 갱신을 분리합니다. 오답의 **다시하기**는 같은 실습을 즉시 재시도하므로 예시를 다시 강제하지 않습니다.

## 조작 비교

|경로|이전|변경|
|---|---|---|
|진행된 규칙 레슨에서 예시 보기|시연 버튼 1회 추가 클릭|진입 시 0회, 자동 재생|
|팝업 기본 버튼(보드 칸 제외)|7개|3개: 닫기/스킵, 멈춤, 핵심 버튼|
|완료 후 화면의 주요 버튼|4개|다음 1개|
|안내 따라 하기 완료 후 혼자 확인 시작|별도 버튼 1회|자동 전환, 0회|
|다른 레슨 고르기|도움 펼치기 → 선택 → 열기|동일; 선택만으로 화면을 바꾸지 않음|

팝업의 이전/다음/다시보기는 ‘재생 조절 · 다시 보기’에 있습니다. 움직임 줄이기에서는 자동 재생하지 않고 이 영역을 펼칩니다. 닫기·ESC·스킵은 같은 결과로 실습에 들어갑니다. 처음 설명을 건너뛰면 안내 따라 하기로 들어가며, 필요하면 보조 영역에서 따라 하기도 건너뛸 수 있습니다.

## 피드백과 기록

사용자가 직접 둔 결과만 보드에 O/X와 한 줄 안내로 표시합니다. 불법 수와 목표에 맞지 않는 합법 수를 구분합니다. 승격 선택 전, 시연, 안내 연습과 상대 자동 응수에는 별도의 정오답 판정을 만들지 않습니다. 표시는 1.8초 후 사라지며 클릭을 가로채지 않습니다. 오답의 다시하기는 저장 확인 후 현재 실습의 초기 위치·차례로 돌아가고 이전 시도는 기존 history에 보관합니다. 기존 성공·점수·진단·다른 계정 상태를 지우지 않습니다.

진행된 독립 확인에서 실제 정답 예시를 보면 기존 도움 열람 기록을 사용합니다. 이를 ‘도움 없이 성공’으로 표시하지 않습니다. 이미 완료된 결과는 소급 변경하지 않습니다. 마지막 단계는 앞서 본 **같은 문제**의 직접 확인이며 새 위치의 숙련 검증이 아닙니다.

## 근거 및 검증

[Chess.com Lessons](https://support.chess.com/en/articles/8609703-how-do-lessons-work-on-chess-com)의 설명과 상호작용 연습 연결, [Lichess Learn](https://lichess.org/learn)의 개념별 기초 연습 구분을 참고했습니다. 이번 웹 열람에서 Lichess의 동적 세부 UI까지 검증했다고 주장하지 않습니다. 외부 영상이나 미디어를 복제하지 않고 기존 합법 수 검증 예시를 재사용합니다.

로컬 Chromium/API에서 320×650, 390×844, 844×390, 1366×768 및 125% 확대를 검사합니다. 자동 진입/저장된 게스트·계정 이어하기, focus trap/복원, 스킵·ESC, 반복 진입, 화면 이탈·로그아웃·숨김, reduced-motion, 지연 응답, O/X·승격 취소·재시도와 기록 보존 검사를 포함합니다. 최종 검사 수와 CI 상태는 PR 본문에 기록합니다. 물리 Kakao/iOS와 실제 스크린리더는 미검증입니다.

### 화면 조작 목록

- 항상: 학습 선택으로(뒤로), 연습판, 도움 · 다른 연습 펼치기. 실습 중에는 추가 시작 버튼 없이 말을 둡니다.
- 결과: 정답이면 다음(마지막 레슨은 활동 선택), 오답/진행 불가면 다시하기. 서버 저장 중에는 진행을 잠시 막고 저장을 확인합니다.
- 도움 내부: 보드 대신 도착 칸 선택·이동, 현재/직전 문제 시연, 같은 문제 직접 다시, 필요할 때 설명부터 다시·안내 건너뛰기·상대 첫수 다시보기, 레슨 선택·고른 연습 열기, 이전 기초 과정.
- 저장 실패/충돌 때만: 저장 위치 확인, 기기 이동을 보관하고 서버 위치로 이어가기. 이 복구 조작은 숨기지 않습니다.
- 팝업 기본: 닫기(스킵과 동일), 멈춤/재생, 스킵하고 연습(마지막 프레임에서는 연습 시작). 보조 영역: 이전 수·다음 수·다시 보기.
