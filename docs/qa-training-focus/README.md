- 훈련의 선택적 바로가기 목록은 실습 아래로 이동했다. 중복 판정 요약 대신 기존 전체 메시지와 상세 해설을 유지한다. 컨테이너 실제 폭700px 이하에서는1열로 전환하여 확대 상태의 작은 보드를 방지한다.
