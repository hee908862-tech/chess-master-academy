# 2B 교육 경로: 범위와 검증

기준 main: df164e1188e6b46c4ddf963624a1cf2b163ce146. 별도 `education_paths_v1` 상태이며 점수식·진단 버전·추천5개·7일 검증·레퍼토리 집계는 변경하지 않는다.

## 중복 검토와 완료 기준

기존 기초10과정26단계에는 체크 대응, 기물 이동, 보호, 승격, 메이트/스테일메이트가 있다. 기존 전술31과목의 정답 퍼즐을 복제하지 않는다. 새로운 6개 경로18관찰은 규칙 설명을 반복하는 대신 공격선/되잡기, 열린 파일/활동 제한, 오포지션의 차례/승격 직후 종료 비교를 자체 구성했다. 관련 기존 기초 카드로 읽기 전용 이동하며 그 과정이나 진행 세션을 자동 시작하지 않는다.

아카데미 기존 허브 → 교육 경로 → 읽기·칸 관찰/착수·이유 비교 → 완료/중단 보관 → 설명 가린 복습. 새로고침으로 같은 위치를 이어간다. 한 경로 약5분, 분야별 하나씩 약15분은 추정 권장량이며 묶음 자동 생성·타이머·점수가 아니다. 진단과 연결은 진단에서 이어진 개념 읽기 단계에 실제 `defensiveMove` 태그가 있을 때만 일반 관찰 연습 링크를 제공한다. 동일 전술 구조나 개인 원인을 추론하지 않으며 독립 확인 중에는 노출하지 않는다.

## 출처와 자체 작성

직접 열어 확인한 공개 자료:
- https://lichess.org/practice — 실습 분류와 폰 종반의 교육 범위 참고.
- https://www.chess.com/lessons/candidate-moves — 공개 소개의 후보 비교 관점 참고. 영상/유료 강좌를 복제하지 않음.
- https://www.chess.com/terms/opposition-chess — 직접 오포지션의 배치/차례 정의 참고.

FEN, 문제, 허용 응답, 한국어 설명은 자체 작성. 출처의 문제·강좌·문장을 복제하지 않았다. Python-chess로 모든 위치·허용 착수/예시 응수 및 공격선/폰 차단/킹 공격/즉시 종료 사실을 검사한다. 허용 목록 밖 합법 수는 이번 수업 범위 밖이며 나쁜 수 판정이 아니다. 계획 후보를 유일 최선으로 주장하지 않는다.

로컬 테이블베이스나 완전 종반 탐색은 확보하지 않았다. 따라서 장기 승패·이론상 승리·강제 손실은 주장하지 않는다. g7 퀸 승격 후 즉시 스테일메이트와 룩 승격 후 유일 합법 수 Ka2가 남는다는 규칙 사실만 비교한다. 오포지션도 차례와 킹 인접 금지의 관찰로 한정한다. 교육 효과/전략 숙련 인증은 미검증이다.

## 저장·버전·한도

계정별 기존 field CAS, revision, write_id를 사용. 시도에 콘텐츠 버전과 원문 스냅샷, 레슨/단계ID, 위치, 입력, 도움, 시각을 저장한다. 개정 시 기존 시도를 자동 변환하지 않고 보관 후 새 시작을 요구한다. 재시도는 보관 후 명시적 시작이며 레슨 누적 도움/다른 응답을 유지한다. 최초 무도움 숙련 점수는 만들지 않는다.

64개 보관, 시도256행, 1MiB. PR17의 종료 자리 예약/예외 보존 함수를 재사용한다. 한도에서 새 쓰기는 거절되지만 읽기·중단 보관·기존 탐색은 가능하다. 1MiB를 이미 넘은 예외 상태도 종료 메타데이터 변경을 허용한다. 입력/힌트 한도에 도달한 미완료 시도는 완료로 위장하지 않고 중단 결과로 보관한다. 자동 삭제·내보내기·무제한 보관은 없다.

요청별 token/세대 확인과 탭 전환 무효화로 이전 계정의 응답을 버린다. 후속 자동 쓰기 연결은 만들지 않는다. 저장 오류는 재조회 전 입력을 잠그며 홈 복귀는 가능하다. 일반 사용법은 도움 이력을 변경하지 않는다.

PR17 운영 요청: 보관 목록에 실제 저장된 `side`, 시작 시각 `at`만 표시. 구형 누락은 색/시각 미기록으로 표시하며 집계/데이터를 추정하지 않는다.

## 후순위

개인 실수 메모는 기존 오답·도움 이력과 중복을 검토한 뒤 자유 텍스트 보존/용량/검색 설계를 따로 진행한다. 영구 복기 변형은 현재 임시 분기·북마크와 일부 중복하며 원본 기보 불변, 분기 버전·충돌·보관 정책을 별도로 검증해야 한다. 이번 교육 경로에 합치지 않는다. 이 PR은 전체 개편의 완료가 아니다.
