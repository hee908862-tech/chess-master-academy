# 첫 방문·로컬 룩 체험·탐색 구조

기준 main: `c9499ec869fe82ff7cfca32385af7a06bd06b980` (PR20 병합). 같은 환경 `/tmp/cma-first-visit` 작업 트리에서 구현했다. 서버 Python, 의존성, DB 스키마, 평가/대국 규칙, 기존 기록 형식은 변경하지 않는다.

## 반영 범위

- 비로그인 첫 홈: 큰 ‘체스가 처음이에요 · 말 움직여 보기’, 보조 ‘체스를 둘 줄 알아요 · 건너뛰기’. 체험 중에도 나가기/건너뛰기 제공. 홈/도움말에서 다시 열 수 있다.
- 기존 `rook-bishop` 첫 과제의 FEN 및 a1→a4만 로컬에서 시연한다. `test_first_visit_contract.py`가 원본 콘텐츠와 합법성을 대조한다. 기초 API·진단·대국 API로 체험 착수를 전송하지 않는다. 체험 성공은 정식 완료·점수·독립 수행으로 이전하지 않는다.
- 방향키로 체험 칸 이동, Enter로 기물/목적지 선택. 기존 표시 테마/기물 설정을 재사용한다.
- 로그인은 기존 코드/PIN 양식과 API. 로그인 연결 취소/중복 클릭/늦은 응답의 계정·목적지 덮어쓰기를 막는 클라이언트 요청 세대를 추가했다. 가입에 성공한 **새 계정만** 빈 기초 상태를 다시 확인한 뒤 기존 CAS 시작 동작으로 첫 정식 과제를 연다. 기존 코드 로그인은 기존 활동을 먼저 보여준다. 기록이 없는 기존 계정을 임의로 ‘새 계정’이라고 추측하지 않는다.
- 기존 코드 로그인 시 저장된 기초의 과정명·단계와 이어하기를 홈에 노출한다. 진행 중 진단/훈련과 기존 추천 주기·7일 기억 확인은 기존 홈 판단을 유지한다. 시작 수준 선택은 계정/도움말에서 계속 제공하며 로그인 직후 강제 모달을 열지 않는다.
- 주요 메뉴: 홈/배우기/실력 진단/대국/내 기록. 배우기 펼침 메뉴와 허브에서 기초/전술/맞춤 훈련/퍼즐/오프닝/저장 활동을 찾는다. 기존 부가 도구는 PC 보조 목록 및 내 기록의 ‘기능 전체 · 도움말’로 유지한다. 메뉴 열기만으로 공통 tab() 이동을 호출하지 않는다.

## 저장·보존 경계

체험 선택/착수/성공/로그인 목적지는 JS 메모리에만 있다. 화면 나가기/새로고침 후 정식 기록으로 복원하지 않는다. `cma_entry_preference_v1=explore`는 이 브라우저의 활동 선택 화면 선호일 뿐 계정 식별자·기보·완료 증거가 아니다. 로그인 토큰/계정 저장은 기존 방식 그대로다. 새 로그인 이후에도 이미 시작된 기초가 있으면 자동 교체하지 않는다. 실패 시 상태를 다시 조회하도록 기존 기초 오류 흐름을 사용한다.

## 검증 구분

실제 신규 Chromium 컨텍스트와 로컬 SQLite 임시 계정으로 체험/건너뛰기/새로고침/신규 가입/기존 코드 로그인과 기초 진행 보존을 검사한다. 지연 로그인·계정 변경·지연 기초 GET은 통제 응답 검사다. 신규 체험 중 서버 쓰기 0과 기존 인증 endpoint의 401을 검사한다. 자동 검사 및 작성자 관점 화면 점검이며 실제 체스 초보자 대상 사용성 검증은 아니다.

PC 1366×768, 모바일 360×800/390×844, 320px, 가로 844×390, CSS 200% 확대를 구분한다. CSS 확대는 브라우저 네이티브 확대/물리 모바일을 대신하지 않는다. 이전 PR의 통과를 이번 결과로 재사용하지 않는다.

## 환경 제한

루트/Docker/기존 PostgreSQL 볼륨 파일시스템 여유 0, `/tmp` 여유 약 8GiB. 최신 이미지 빌드/이미지 HTTP/PostgreSQL 쓰기 검사는 미실행이다. 이전 코드·로그·캡처·DB·사용자 자료를 삭제하지 않았다. main 병합/배포는 부모 검토 단계이며 이 작업에서 수행하지 않는다.
