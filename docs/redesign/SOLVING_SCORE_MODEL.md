# 풀이 수행 점수 v1

이 문서는 `solving_score.py`의 순수 계산 계약을 설명한다. 기존 실력지표·경험치·게임점수·원본 진단 기록을 변경하지 않는다. 저장·권한·시점 검증은 호출자의 책임이다. 새 `solving_score`만 별도 저장하며 버전이 없는 과거 기록을 자동 재채점하지 않는다.

## 범위와 가정

버전은 `solving-performance-v1`, 시간 입력은 `solving-time-v1`, 목표 시간 정책은 `authored-target-v1`이다. 문항·보고서에 목표 시간 정책 버전을 별도로 제공한다. 모든 계수와 목표 시간은 저자 설계다. 난이도로 교정된 능력, Elo, 정확도 보장이나 통계적 신뢰구간이 아니다. 외부 문제 rating은 목표 시간 T에만 쓰고 정답 판정이나 A 가중치를 바꾸지 않는다. 외부 rating이 실제 풀이 난도를 정확하게 표현한다는 보장도 없다.

실제 0ms 기록은 시간 누락과 구별하여 `zero_duration_below_resolution`으로 보류한다. 1ms 등 양의 1초 미만 측정은 반올림해 0으로 만들지 않는다.

독립적인 첫 미노출 시도만 확정 수행 점수 대상이다. 도움·재풀이·기출·독립성 미확인은 원래 수행 근거와 연습 기본점을 표시하되 확정 점수는 보류한다. 누락된 독립성 필드를 참으로 추정하지 않는다. 이미 배정된 미확정 문항을 분모에서 빼서 만점으로 만들지 않는다.

## 계산

목표 완수의 A는 1이다. 확정 실패·건너뛰기·부분 수행의 A는 `0.5 × 확인된 선택 가능 내 수 / 원래 선택 가능 내 수`이며 최대 0.5다. 합법수가 하나뿐인 강제 수는 부분 수행 분자·분모에서 제외한다. 원래 합법 수순을 FEN부터 재생하고 저장된 제출 prefix와 맞는 수행만 인정한다. 이것은 핵심 기술이나 능력 추정이 아니다. 대체 수순의 부분 실행을 원래 수순으로 추정하지 않는다. 완료되지 않은 동등 대안·미검증 대안은 A와 최종 점수를 보류한다.

목표 시간(초):

```
T = clamp(30 × (1 + clamp(rating−600, 0, 1800)/1200)
          × (1 + 0.5×max(선택수−1,0) + 0.15×강제수) × 유형계수, 15, 300)
```

유형은 명시된 대표 분야를 사용한다. 메이트 1, 기물 획득 1.1, 방어 1.2, 계산 1.2, 승격·종반 1.3이다. 태그에서 새 목표를 추측하지 않는다. 원본 FEN·합법 수순·rating·분야가 없거나 잘못되면 목표 시간을 만들지 않는다.

독립 완수이며 강제 수만 있는 문제가 아니고 유효 시간이 있을 때 B는 `clamp(2−t/T,0,1)`이다. 명시적 중단은 시간 가산 0으로 설명한다. 시간 미측정·불확실은 빠르게 또는 느리게 풀었다고 간주하지 않고 최종 점수를 보류한다. 오답·미완료·모두 강제 수인 문제에는 시간 가산이 없다. 실제 기록된 시간은 가산 자격과 분리해 표시한다. 시간 입력은 서버 교차 검증 모듈이 제공하며 집중이나 부정행위 부재를 증명하지 않는다.

```
최종 = 1 + ROUND_HALF_UP(2849×평균 A + 150×평균 B)
기본점 = 1 + ROUND_HALF_UP(2849×평균 A)
시간조정 = 최종 − 기본점
```

각 원래 배정 문항을 동일 가중치로 한 번씩 포함한다. 같은 배정 ID의 동일 사본은 중복 제외하며 내용 충돌은 보류한다. 다른 배정 ID라도 같은 문제·겹치는 수순 위치면 반복 근거로 분리하고 분모를 유지한다. 최종 점수 범위는 1~3000이다. 기본점과 시간조정을 각각 먼저 반올림하여 더하지 않는다.

## 예시와 한계

- 독립 완수, 충분히 짧은 유효 시간: 2850 + 150 = 3000. 전체 체스 숙련 만점을 뜻하지 않는다.
- 독립 완수, 2T 이상 유효 시간 또는 명시적 중단: 2850. 시간 불확실은 같은 2850을 확정하지 않고 기본점만 표시한다.
- 선택 가능한 내 수 두 번 중 한 번만 확인: A=0.25, 기본점 713, 시간 가산 0. 어려운 문제라고 부분 수행이 쉬운 목표 완수보다 높아지지 않는다.
- 확정 오답 1개와 완수 1개, 시간 가산 모두 0: 평균 A=0.5, 최종 1426.
- 8개 완수와 2개 판정 미확정: 최종 보류. 성공한 8개만으로 3000을 확정하지 않는다.

## API와 검증

`target(item)`, `item_score(item)`, `report_score(report)`는 입력을 변경하지 않는다. 문항 결과는 A/B, 기본점/시간조정/최종점, target, execution, time, reasons를 반환한다. 최종이 없으면 null이며 0점으로 대체하지 않는다. 보고서는 모든 배정 문항과 집계 보류 이유를 함께 반환한다. `time.measurement_status`는 측정 상태, `time.status`는 시간 가산 평가 상태다.

순수 테스트는 연속 rating 민감도, 시간 단조성, 경계·반올림, 빠른 오답과 느린 정답, 선택 수·강제 수, 미확정·도움·기출, 원본 보존, 손상된 시간, 중복 배정 및 동일 가중 분모를 다룬다. 이 테스트는 사용자 응답자료를 통한 계수 교정 또는 실제 엔진·운영·모바일 검증이 아니다. 새 점수와 기존 점수를 같은 시리즈로 비교해서는 안 된다.
