# 원래 시도·부분 수행·시간 분리 검증

기준 main: `ae80d16901cdf40385b25d3ed9e8bdc8619d4c2c` (PR45). 운영 계정/답안/점수는 조회·재채점하지 않았다. 테스트는 격리 SQLite와 합성 데이터이며 사용자별 이력은 이 문서에 포함하지 않는다.

## 구현 및 보존

- 기존 기초40/응용60 선형 1~3000은 선택 관찰 수행점수로 보존한다. 새 전체 시도 요약은 미확정·검증된 오답·명시 미완료·미응답 배정을 구분한다. 대체 성공이 앞선 미확정을 지우지 않는다. 논리적 완료율 경계는 통계적 신뢰구간이나 능력 레이팅이 아니다.
- 원래 보고서/문항/전체 원본 해시로 재검증을 한정한다. 완료 회차의 저장 답안만 소유자 인증 후 처리하며 새 착수를 받지 않는다. 요청 키는 멱등, 계정당 10초 간격, 문항별 최대3회/계정 이력512건, 프로세스 동시1건, 규칙 탐색6000노드/150ms다. 이는 운영 상한이며 정확도 보장이 아니다. 중단된 pending도 예산을 소모하며 30초 동안 추가 요청을 막는다. 원본과 고정 기준선은 수정하지 않고 별도 교정 이력과 읽기 투영을 남긴다.
- 현재 재검증은 남은 내 수3회 이하의 N수 메이트만 지원한다. 완전 탐색으로 목표 실패 또는 실제 제출 즉시 메이트를 확인할 때만 최종 교정한다. 가능한 후속 수순을 아직 직접 실행하지 않았다면 완료 정답으로 바꾸지 않는다. 일반 기물 획득/유리함/무승부의 동등 정답은 미완성이다.
- 외부 문항 난도 실제 값, 목표 달성, 확인된 내 수 n/m, 합법 수 하나인 강제 이동과 선택 가능한 이동을 구분한다. n/m은 관찰된 수순 완성도이며 핵심 판단 가중치나 능력 점수로 환산하지 않는다.
- 시간은 브라우저 보고 값이며 신뢰 가능한 능력 척도가 아니다. 대기/애니메이션/숨김/명시 중단을 제외하고 서버 경과시간으로 상한을 제한한다. 과거 기록은 미측정이다. 동일 외부 난도·주제·필요 내 수·분야·평가 범위·버전·문제은행의 정확한 독립 완료만 참고 비교한다. 최소3개 중앙값/앞뒤3개 비교는 표시용 설계 기준이며 보정된 정밀도가 아니다. 일시정지·재검증·도움·반복은 비교 제외한다.
- 결과는 요약과 다음 행동 우선, 문항별 근거는 기본 접힘이다. 원래 점수와 재검증 결과를 함께 설명하며 과거 보고서에도 사용자가 직접 선택한 문항만 재검증한다. 관찰0인 다른 분야 회차는 해당 성장 목록에 넣지 않지만 원본은 보존한다.

## 검증 범위

- 순수 집계18개: 성공8+미확정2, 교정된 실패, 도움/기출/반복, 미확정 독립성, 미응답·부분 수행, 분기 복원, 원본 해시/정책, 시간 그룹.
- 시간31개: 서버 단위24, 로컬 Chromium5, 실제 로컬 API+Chromium2. 잘못된 선택적 시간값으로 답안을 거절하지 않음, 지연/중복/reload/배경/중단/애니메이션 포함.
- 수행 UI16개: PC1366×768, 모바일 에뮬레이션360×800/390×844, 키보드,72문항 접힘, 가로 넘침, 소유 정체성 변경 뒤 늦은 응답, 명시 요청과 실패/상한 안내. API doubles와 컴포넌트 검증이다.
- 통합 서버/보존/초기 과정/채점/패키징44개 선택 실행에서 초기 POST 응답과 GET 근거 투영 차이1개를 발견해 고쳤다. 나머지43개 통과, 해당 초기/연속 과정16개 재실행 통과. 별도 최종 선택에서 실제 Stockfish 포함 재검증6개와 Docker COPY 패키징5개 통과.
- 기존 초기 연속/접근성/익명 진입/훈련/성장/착수음 브라우저29개 중27개 최초 통과. 변경한 점수 제목과 신규 성장 합성 fixture의 조회 경합/불완전 프로필을 수정했다. 시간 그룹 fixture도 서로 다른 외부 난도를 같은 비교로 기대하지 않도록 수정했다. 이는 제품 기준을 낮춘 변경이 아니다.
- 실제 Stockfish17.1은 공개 합성 국면의 메이트 목표 실패와 상대 방어를 독립 확인한다. 서버 원래 실패 시점 로그 재현이나 실제 계정 재채점이 아니다. 재검증 자체는 제한된 전수 규칙 증명이며 엔진 평가를 성공으로 추측하지 않는다.
- 성능 참고: 로컬 합성48문항 읽기 요약5회 17.13–20.09ms. corpus 초기 로딩 제외. 운영 지연 개선 수치가 아니다.

## 운영 및 미검증

기존 Render 자동 배포만 사용한다. Live 커밋 확인은 운영 UI 검증과 구분한다. 이전 운영 접속 프록시403을 우회/반복하지 않았다. 운영 재검증 쓰기·신규48완주, 실제 모바일 기기, 실제 초보자 관찰, PostgreSQL 동시성 부하 및 실제 이미지 빌드는 이번 로컬 검사로 주장하지 않는다. Docker COPY 검사와 로컬 Chromium 에뮬레이션을 각각 구분한다. 기존 운영 API 지연의 해결도 주장하지 않는다.

운영 읽기 재검수: 초기 결과 → 전체 시도 요약 → 문항별 근거 → 원본 점수 설명, 내 정보 → 선택 분야 성장 목록. 실제 계정 재검증 버튼은 사용자 의사 없이 누르지 않는다.

난이도 보정 능력 추정/Glicko 도입은 실제 집단 응답 교정이 더 필요하다. 검증되지 않은 속도 가중치나 고난도 배수를 넣지 않았다. 설계 참고: [Chess.com의 레이팅 변경 설명](https://support.chess.com/en/articles/12488563-why-did-my-puzzle-rating-change), [ETS IRT 소개](https://www.ets.org/Media/Research/pdf/RM-20-06.pdf), [Ofqual의 평가 속도 연구](https://www.gov.uk/government/publications/time-limits-and-speed-of-working-in-assessments/time-limits-and-speed-of-working-in-assessments-when-and-to-what-extent-should-speed-of-working-be-part-of-what-is-assessed). 문구·그림을 복제하지 않았다.

최종 결과: 수정된 초기 훈련 제목 검사는 최종 선택 실행에서 통과했고, 성장 브라우저1개+순수 집계18개 재실행은 **19개 모두 통과**했다. 위에 기록한 제품 응답 투영 결함과 fixture 실패는 해결됐으며 현재 알려진 검사 실패는 없다. 독립 읽기 검토에서도 추가 배포 차단 문제는 발견되지 않았다. 각 검사군은 재실행이 중복되므로 합산 실행 횟수를 고유 검사 수로 제시하지 않는다.
