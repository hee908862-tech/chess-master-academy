# 공통 착수음

- 브라우저에서 짧게 감쇠하는 탁 소리를 합성한다. 외부 음원·네트워크 다운로드·새 라이선스 의존성 없음. 기존 음색 선택과 음소거 유지, 브라우저 로컬 음량 0–100 추가(기본 70).
- `board-presentation.transition`이 명시된 수와 실제 전후 기물 배치가 일치하는 경우만 소리를 낸다. 단순 선택·동일 배치 재렌더·판정 문구·다른 문제의 새 배치는 무음이다. 캐슬링 두 기물은 한 수로 한 번, 제출+응수는 두 번이다.
- 이동 애니메이션 줄이기와 소리는 독립이다. 숨겨진 보드·백그라운드·계정 변경·취소된 재생에서 지연된 소리가 나지 않는다. 브라우저 오디오 차단 시 소리를 쌓아 두지 않는다. 사용자 실제 포인터/키보드 조작에서만 AudioContext를 열고 차단된 resume 거부는 처리한다.
- AI 대국·v9 퍼즐의 합법 목록으로 확인한 낙관적 착수는 화면에 실제 적용된 때 소리가 난다. 서버가 목표 오답/실패로 되돌릴 때 복구 렌더는 무음이다. 소리는 정답이나 저장 성공을 뜻하지 않는다.

## 적용 보드 인벤토리

| 화면 | 적용 경로 |
|---|---|
| 대국/이전 평가 대국 | 내 착수·서버 응수·되돌리기 transition; 이전 직접 음원 호출 제거 |
| 초기/종합 진단 | 서버 확정 착수/응수 및 제출 후 답안 시연 transition |
| 퍼즐·전술 과정·도전 | 적용된 합법 착수/응수 transition; 목표 오답의 배치 미변경은 무음 |
| 기초·룩 체험·게스트 예제 | 실제 착수 및 앙파상 상대 폰 시연 transition |
| 훈련실 | 착수/무르기/인접 복기 프레임 transition |
| 오프닝·복기 | 인접 이동·되돌리기 transition; 직접 호출 중복 제거 |
| 진단 상대 응수 재생 | 인접 이전/다음·자동 재생 transition |
| 레퍼토리·교육 | 서버 반환 실제 착수 기록 및 답안 적용 transition |
| 대국 관찰 장면 | 실제 내 수 전/후 전환에 기록된 UCI 기반 transition |
| 분기 탐색 | 합법 분기 착수·이전 수 transition (탐색 모듈 통합) |
| 정적 홈/결과/메이트 관계 설명 | 이동이 없는 선택/자료 표시이므로 무음 |

이전 시작 수준 맛보기의 문항 교체는 적용된 수를 그리지 않고 다음 문제로 이동하므로 교체 자체는 무음이다. 현재 기초 선택은 별도 기초 과정으로 연결된다. 잘못된 FEN을 만들어 이동음만 내거나 판정을 성공음으로 바꾸지 않는다.

## 검증

로컬 Chromium 착수음 8개 + 기물 배치/명시 수순 계약 4개 + 실제 이동 연결 5개 = 17개 통과 (`/tmp/cma-sound-integrated.xml`). 일반 이동·캐슬링·앙파상·승격·되돌리기, 무효 적용/선택/중복 렌더, 두 반수 및 취소·계정 변경, 음소거/0음량/음량 비율, 오디오 차단 처리, 새 브라우저 페이지의 설정 복원, 실제 로컬 오프닝 API 착수/되돌리기, 진단 복기 재생(합성 프레임·쓰기 없음)을 검사했다.

브라우저 오디오 노드와 이벤트 횟수 검사이며 실제 스피커 음질·모바일 실기기 청취는 미검증이다. 이동음은 성능 수치나 저장·정답 보증이 아니다. 전체 motion suite의 훈련 완료 검사에서 과거 label DOM을 찾던 단언을 현재 SVG 시각화 계약으로 수정한 뒤 5개 모두 통과했다(음원 구현 오류는 아니었다). 최초 새 검사 실패 중 두 반수 타이머가 resize로 취소되던 문제는 수정했고, 설정 복원 fixture와 접힌 오프닝 설정/다른 보드 음원 계수는 실제 흐름에 맞게 교정했다.

닫힌 해설(details)/대화상자/비활성 화면은 배치가 갱신돼도 무음임을 별도 검사 1개로 확인했다 (`/tmp/cma-sound-hidden.xml`, 1 통과). 최종 고유 검사 합계 18개이며 재실행은 중복 계산하지 않는다.
