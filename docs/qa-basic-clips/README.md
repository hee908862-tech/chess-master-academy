# Optional basic lesson board clips

The parent inspected the three supplied screenshots; this execution environment's supported Library transfer failed twice and did not provide pixels. Implemented against the parent's verified descriptions and checked the actual lesson FENs: 25/62 promotion, 32/62 shield, 57/62 stalemate.

- All 45 authored rule lessons have opt-in demonstrations from their initial FEN. Legal moves and educational replies are generated by the existing rule replay, then checked one ply at a time. Placement/square examples remain visibly distinct from chess moves.
- Controls: play/pause, previous/next, reset, close. No autoplay; animation honors the existing reduced-motion setting. Current practice moves survive preview and previous-lesson preview. Route exit cancels; tab hiding pauses.
- Viewing records `demo_views` and `helped` in movement state before returning the answer. It never adds practice moves, completes a lesson, or writes assessment/game/account data. Exposure survives restart. Existing compare-and-save conflict and account-generation boundaries remain in force.
- Rule lesson completion waits for an explicit next action; same-piece movement exercises keep their existing automatic progression.
- Mobile navigation follows content rather than covering it; safe-area padding and compact clip controls keep feedback reachable without scaling the board down.
