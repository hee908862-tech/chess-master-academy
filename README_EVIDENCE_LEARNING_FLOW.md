# 수행 근거에서 학습으로 이어지는 첫 단계

기준 main `98669fab1f1cf3b1423148b2ffd6b67a736ea49b`. 다음 개편의 첫 단계이며 전체 교육 개편 완료를 의미하지 않는다. 부모 검토 뒤 병합·운영 확인하며 이 작업에서는 병합·배포하지 않는다.

## 조사와 완료 기준

| 구분 | 확인 내용 | 이번 범위 |
|---|---|---|
| 사용성 | 구체적인 제출 근거는 여러 겹 접혀 있고 추천 5개와 독립 확인이 떨어져 있음 | 추천에 원본 문항·제출·비교 수를 연결, 새 적용과 반복을 구분, 선택 분야 독립 확인 진입 |
| 사용성 | 홈에 중복 행동, PC 아카데미가 중앙 모달 | 저장 활동 우선 행동 하나, 추정 시간과 근거, 자유 탐색은 펼침; PC 옆 펼침/모바일 시트 |
| 교육적 한계 | 24문항은 분야별4개, 검증된 종합 능력 검사가 아님 | 표본과 판정 보류를 명시, 심리 원인을 추측하지 않음 |
| 교육적 한계 | 연습 5개 완료와 독립 숙련은 다름 | 원본/새 적용/도움 없는 수행/7일 기억 확인을 서로 구별 |
| 검증 부족 | 장기 교육 효과, 전략·위협·일반 종반의 검증된 교육 자료 | 이번 단계 효과를 입증했다고 주장하지 않음. 별도 후속 범위 |

새 scoring/version 모델, 과거 기록 재채점, 새 강좌, 신규 비용/인증 변경은 추가하지 않는다. 저장된 진단과 훈련, 5개·gentle·7일 조건, 기초10과정26단계, 오프닝55강, 퍼즐 도전·복기 원본을 유지한다.

## 구현 원칙

`learning_observation`은 저장된 FEN·원본 수순을 python-chess로 검증하고 실제 제출 수가 일치하는 prefix만 따라간다. 다른 합법 수에서는 원본 비교를 멈추며 그 대안 이후의 수를 지어내지 않는다. 체크/포획/캐슬링/승격/메이트 사실은 해당 실제 보드에서만 계산한다. 기존 outcome과 엔진 판정은 그대로 표시한다. 이 정보는 GET의 별도 `learning_evidence`에 반환하며 보고서나 저장 상태를 수정하지 않는다. 불완전·불법 원본은 구체 수를 생성하지 않는다.

추천은 기존 계획의 item_id를 그대로 사용한다. 태그 공통성을 구조의 동일성으로 표현하지 않는다. 무응답을 오답으로, 보류를 엔진 손실로 바꾸지 않는다. 훈련의 진단 연결은 설명 가능한 연습 또는 종료 뒤에만 제공하며 진행 중 verify에는 새 메타데이터를 숨긴다. 기존 개념/경로를 재사용한다.

PC 메뉴는 `dialog.show()` 비모달 펼침으로, 모바일은 `showModal()` 시트로 연다. 공통 tab()은 항목 선택에만 호출한다. Escape/외부 클릭/PC Tab 이탈은 메뉴만 닫고 복기 분기·엔진 요청을 취소하지 않는다. 모바일은 기존 포커스 순환을 유지한다.

홈은 진행 중 진단 → 진행 중 훈련 → rules-first 기초 → 가능한 기억 확인 → 결과/추천 순으로 안내한다. 기본 권장 시간이 아닌 명시적 추정 시간이며 시간제한은 없다. 저장 조회 실패 때는 기존 권장을 실행시키지 않고 상태 재조회로 안내한다. 기초·기타 저장 활동과 자유 모드는 ‘직접 고르기’에 유지한다.

## 검증

최종 head, 관련/전체/격리 PostgreSQL 및 Chromium 캡처 결과는 `docs/qa-evidence-flow`에 정리한다. 과거386/PG16 통과를 이번 결과로 재사용하지 않는다. 운영 브라우저, 물리 모바일/Safari, 장기간 교육 효과는 이번 로컬 검사와 별도다.
