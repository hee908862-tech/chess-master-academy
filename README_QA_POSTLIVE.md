## 검증 결과

최종 변경에 해당하는 **129개 행동 테스트 통과**(분할 실행, 중복 재실행 제외): API/상태 54개, Chromium 75개. 기존 학습 API 테스트의 실제 Stockfish 경계 검사도 포함한다. 임시 SQLite 및 합성 로컬 계정만 사용한다. 네트워크 유실/지연 테스트는 실제 Chromium에서 API 응답을 제어하며 운영 네트워크 재현을 주장하지 않는다.

```sh
python -m pytest -q tests/test_learning.py tests/test_review_assistance.py tests/test_qa_behavior.py tests/test_followup_state.py
python -m pytest -q tests/test_learning_browser.py tests/test_board_interaction.py tests/test_qa_browser.py tests/test_qa_followup_browser.py tests/test_review_assistance_browser.py tests/test_followup_browser.py
python test_qa_work_regression.py
python test_v9_static.py
```

- 통과: Python 전체 루트/테스트 AST 구문, public 전체 JS `node --check`, QA 정적 계약, v9 정적 검사, `git diff --check`.
- 수정 과정 실패 후 해결: 기존 프리무브 취소 테스트 3개는 보드 앞 형제 위치를 고정한 선택자를 실제 해당 보드의 조작 요소로 갱신했다(취소 동작 검증 유지). 기존 진단 상태 테스트 1개는 중복 2요청을 전제했으므로 single-flight 1요청과 완료 화면 보존을 검증하도록 갱신했다. 각각 취소 전체 21개 및 QA 브라우저 전체 13개 재실행 통과.
- 기존 실패 유지: `test_v81_regression.py`의 “7개 영역 중 메이트 한 영역” 문자열 계약, `test_v3_static.py`의 구형 2개 script 목록 계약. 이번 동작 회귀 실패와 구분한다.
- 미실행: 전용 타입/린트 도구 설정이 없어 해당 검사는 실행하지 않았다. 운영 PostgreSQL/다중 인스턴스 부하/실물 모바일·Safari/Render 배포 검증도 하지 않았다.
- Starlette/httpx deprecation 경고 1종. 문제은행 blob은 main과 동일한 `efb19b7b720cc5f3a1c033c41d212c0cd708ec89`.

## 검토자가 반복할 짧은 체크리스트

1. 임시 신규 로컬 계정으로 로그인하고 오늘 경로를 시작한다. 첫 입문 문제와 미완료 상태를 확인하고 한 번 풀어 개념 단계로 이동한다.
2. 퍼즐 시작→착수 요청 응답 유실을 재현한다. 저장된 완료 또는 원래 위치로 복구되며 같은 착수를 자동 재전송하지 않는지 확인한다. 서버 연결까지 끊으면 읽기 전용 위치와 재확인 버튼이 보여야 한다.
3. 진단 시작 응답을 지연시킨 뒤 메뉴를 왕복한다. POST는 한 번이며 지연 안내가 표시돼야 한다. 60초 초과 후 새 시작 대신 상태 확인으로 복구한다.
4. 게스트 퍼즐/진단/훈련실 버튼에서 로그인 안내와 목적 화면 복귀를 확인한다. 복귀만으로 새 대국/진단을 시작하지 않아야 한다.
5. 복기 목록 로딩·실패·빈 목록에서 분석 버튼이 꺼지는지, 정상 목록에서 기존 힌트 채택/다른 수/무르기 라벨이 유지되는지 확인한다.
6. 네 viewport에서 보드, 승격 선택, 프리무브 ON/OFF/취소, 가로 스크롤 없음, 흰 기물 대비를 확인한다. 운영 배포 검증은 별도 승인 후 진행한다.
