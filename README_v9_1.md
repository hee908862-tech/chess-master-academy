# Chess Master Academy v9.1 — 체스판 조작 개선

## 반영 사항
- AI 대국/실력 진단/퍼즐/오프닝의 `drawBoard()` 공통 UI(선택, 합법 이동 목표, 마지막 이동 표시)를 활용
- 퍼즐/아카데미에서 합법적인 이동을 화면에 먼저 반영하고, 서버 채점 후 정답 수순에 따라 진행; 오답은 원래 위치 복구
- 퍼즐/아카데미에서 상대의 마지막 이동 칸 표시, 정답의 UCI 이동 경로 텍스트 제공
- 기록된 정답 수순을 확인할 수 있는 힌트 버튼 추가(첫 시도 정답으로 채점되지 않음)
- 실력 진단의 백/흑 차례별 기물 선택과 이동 가능 목표 표시 오류 수정
- 일반 AI 대국 폰 승격 시 퀸·룩·비숍·나이트 선택 모달 추가. 퍼즐/진단에서도 승격 선택 가능
- 퍼즐/아카데미의 풀이 완료 후 다음 문제 진행 상태 검증을 강화

## 기존 퍼즐 데이터 보존: 가장 중요
이 ZIP에는 `puzzles_lichess.jsonl`을 포함하지 않습니다. 기존 GitHub 저장소의 데이터가 들어 있는 같은 파일을 **그대로 유지**하세요. 절대 빈 파일로 덮어쓰지 마세요. 기존에 생성한 파일을 확인한 뒤 서버에 남아 있어야 합니다.

## GitHub 업데이트
1. 기존 DB 백업 / 환경변수 `DATABASE_URL` 유지.
2. ZIP 내부 `chess_master_academy_v9` 폴더의 파일들을 같은 경로에 교체(기존 저장소의 `puzzles_lichess.jsonl`은 그대로 유지).
3. GitHub Commit 후 Render Live 확인; 브라우저 Ctrl+Shift+R 새로고침.
4. 퍼즐에서 기물 선택→합법칸 표시→이동→채점→상대 응수→다음 문제 확인.
5. 진단에서 백/흑 차례 각각 확인. 일반 대국에서 폰 승격 시 4종 선택 확인.

## 테스트 한계
Python/JS 정적 검사만 수행. 현재 환경에 python-chess가 없어 실제 Stockfish·데이터 파일을 사용한 E2E 검증은 미완료.
문제의 정답은 Lichess 기록 수순 기준이며 동등한 다른 최선 수를 엔진 분석으로 승인하는 기능은 아직 없습니다.
