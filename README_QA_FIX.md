- **QA-02:** `/api/game` 시간패 응답에 마지막 판/잔여 시계/종료 사유/패배 색상을 포함. 프런트 0초 감지 시 서버 상태 조회 및 종료 표시. 움직이는 AI 요청 중 중복 조회는 억제.
- **QA-03:** 진단 추천 버튼을 기존 숨겨진 v6 커리큘럼이 아닌 v9 과정 선택에 연결. 테마 매핑은 키워드 기반이므로 완전한 개인화 매핑은 후속 작업.
- **QA-04:** 최종 퍼즐 성공만 100% 정답률로 집계하던 문제를 보완. `first_try_correct`, `hint_used`, `wrong_moves`를 퍼즐 완료 시 별도 저장. 이전 데이터는 첫 시도 여부를 알 수 없으므로 새 정확도 분모에 넣지 않음.
- **QA-05:** 새로운 v9 학습 이수 세션을 프로필 수치 및 홈 학습 현황에 반영. '숙련' 여부와 단순 '이수'는 서버에서 구분하여 보관.
- **QA-06:** 평가 대국이 유효한 백 착수 12개 미만이면 엔진 평가 30%를 포함하지 않고 문제 기반 예비 점수를 사용. 별도 재평가 강제나 신뢰구간 통계는 아직 미구현.
- **QA-07:** 퍼즐 0개 테마를 선택할 수 없게 하고, 15문항 미만 과목의 시작 버튼 비활성화.
- **QA-08:** 과목 전환 시 이전 체스판·선택·완료 상태·다음 문제 버튼 초기화. 서버 저장 세션 자체는 보존.
- **QA-09:** 중복으로 출력되던 구형 v6 추천 화면 숨김 및 호출 중지.
- **QA-10:** 랜덤 단일 퍼즐 완료 시 `/15` 고정 문구 제거.
